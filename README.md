**把客户提供的 Excel 账簿，变成律师可以方便查询的本地账套。**

非诉律师开展尽职调查时，客户往往只提供从财务软件导出的 Excel 表格，律师通常没有自己的查账软件。要查一笔交易，需要在不同工作表、不同科目之间反复查找；一张凭证又可能涉及几个科目，仅看某个科目的明细，难以看清整张凭证。

DudLedger 的主要用途，就是让律师把这些表格导入后，像使用常规查账软件一样，按科目查看明细、搜索交易、打开凭证，并归集需要进一步核查的记录。

## 一、主要功能

### 1. 从 Excel 查到账簿，再查到凭证

支持导入明细账、序时账，按科目、日期、期间、凭证号、摘要、往来单位等条件查询和筛选。

在明细账中双击记录，可以打开对应凭证，集中查看同张凭证中已导入的各科目分录，减少在 Excel 中来回切换和拼凑信息的操作。

> 凭证展示以已导入的数据为限。客户仅提供部分科目明细时，其他未提供的分录不会自动补齐；账面分录也不包含原始单据或凭证附件。

### 2. AI 辅助导账，减少手动对应表头

不同财务软件导出的表格，列名、表头层数、合并单元格和借贷金额排列方式常常不同。直接导入时，很容易遇到需要手动逐列对应，甚至无法识别的问题。

DudLedger 通过 AI 分析表格结构，识别表类型、表头位置及各列含义，再由本地程序校验并写入 **SQLite 数据库**，形成可反复打开、查询的本地账套。

```text
选择 Excel / CSV
       ↓
AI 读取前 20 行，分析表格结构
       ↓
本机整表预检，展示识别结果和提醒
       ↓
用户确认导入
       ↓
保存为本地 SQLite 账套，查询明细和凭证
```

- **AI 默认只读取每张所选工作表的前 20 行**，用于分析格式和表头；最多 40 列、每格 60 字，并附上该范围内的合并单元格位置。
- 整张表的数据解析、预检和数据库写入在本机完成。这里的“前 20 行”是结构识别样本范围，导入仍处理通过校验的数据行。
- 支持一次选择多个文件和工作表；全部勾选表通过预检后，再点击“确认导入”。存在未解决的关键问题时，会暂停并提示处理。
- 成功导入的表头结构会保存为本地模板，方便以后导入相同格式的账簿。

**前 20 行可能包含真实账目、公司名称和交易摘要。** 使用内置 AI 导入需要配置 DeepSeek API Key，样本会发送至对应模型服务；也可以选择“仅用本地规则和手动设置”。

### 3. 识别不了的表格，交给自己的 AI Agent

遇到复杂表头或内置 AI 无法判断的格式，可以一键点击 **“复制提示词给我的 Agent”**，再粘贴给自己使用的 AI Agent，让它继续分析表头并协助导入。

该入口会准备文件位置、待处理工作表和导入要求。Agent 需要具备读取本机文件及执行命令的能力，才能调用随软件提供的导入工具，完成校验并生成新账套。

外部 Agent 的读取范围取决于你的授权和所用环境，不受内置 AI“前 20 行”的限制。详细流程见 [表头识别导入与 Agent 接手](docs/三层Excel导入与Agent接手.md)。

### 4. 余额表与财务报表辅助查阅

除明细账、序时账外，也支持导入 **科目余额表、资产负债表和利润表**，方便在同一账套中查阅及计算。

资产负债表、利润表以表格展示为主，不自动建立报表项目与各会计科目的关联，也不提供从报表项目自动穿透到凭证的跳转。工具的主要功能仍是查询凭证，余额表和财务报表属于辅助功能。

支持文件格式：`.xlsx`、`.xlsm`、`.xls`、`.csv`。

## 二、附加功能

| 功能 | 用途 |
| --- | --- |
| 选区合计与计数 | 在账表或凭证中框选单元格，即时查看合计、非空单元格数和金额项数；支持多个不连续选区。 |
| 计算器 | 将不同选区的金额加入或减去，保留本次窗口内的计算过程和来源，方便核对。 |
| 关注凭证 | 标记需要复核的凭证、填写备注，并导出关注凭证 Markdown，便于整理核查记录。 |
| 问题工作台 | 按尽调问题归集凭证，记录问题描述和核查笔记；同张凭证可关联多个问题。 |
| AI 凭证初步抽查 | 通过判断模型，按预设或自定义问题筛选值得进一步核查的凭证线索。 |

AI 凭证抽查是独立的可选功能，与导入时的表头识别分开使用。目前支持[阿里百炼决策模型（限时免费）](https://help.aliyun.com/zh/model-studio/decision-model-preview#%E5%8D%8E%E5%8C%972-%E5%8C%97%E4%BA%AC-h4)、[TypeSafe Jev 决策模型](https://typesafe.ai/)和 DeepSeek Flash，固定按“百炼（已确认免费可用）→ Jev → DeepSeek Flash”顺序调用；未配置、额度不足或接口不可用时顺延。未确认百炼免费可用时跳过百炼。

抽查可针对其他应收款、其他应付款、实收资本、资本公积、营业外支出、财务费用等科目，按专项问题判断是否命中，并展示核查建议。**结果用于帮助律师初步筛选问题凭证，最终判断仍需结合合同、流水、原始单据等材料。**

## 三、如何使用

### 1. 下载、解压、打开

以下为**包含运行环境的软件压缩包**的使用方式：

1. 下载适合自己系统的软件压缩包。
2. 将压缩包完整解压到本机文件夹。
3. 在解压后的文件夹中，双击启动程序。

运行环境已随软件打包，无需另外安装 Python 或配置依赖。请保留解压后的完整文件夹，从中启动软件。

> GitHub 的“Code → Download ZIP”下载的是源码。源码运行方式见下文。

### 2. 导入客户提供的表格

1. 打开软件，选择“文件 → （批量）导入表格…”。
2. 选择一个或多个 Excel / CSV 文件；首次导入时，选择账套保存位置和名称。
3. 勾选需要导入的工作表。使用 AI 导入时，先按提示设置 DeepSeek API Key，程序会自动分析表头并运行本地预检。
4. 核对表类型、表头、列对应关系、拟导入行数和提醒。全部勾选表通过后，点击“确认导入”。
5. 如果识别失败，可重试、手动调整列，或点击“复制提示词给我的 Agent”继续处理。

### 3. 查询、计算和关注凭证

- **查凭证：** 在科目总览或明细账中选择科目，结合搜索和筛选定位交易，双击明细记录打开凭证。
- **做计算：** 在账表或凭证中拖动框选，即可查看合计与计数；需要跨选区加减时，打开左侧“计算器”。
- **留记录：** 将凭证加入“关注凭证”并填写备注；需要围绕具体事项整理时，加入“问题工作台”中的相应问题。
- **继续查账：** 下次启动后，选择“打开账套…”，即可继续使用已有账套。

### 4. 按需启用 AI 凭证抽查

第一次打开应用会显示 AI 配置引导，先填写 DeepSeek API Key（导入识别及抽查兜底），再按需配置百炼与 Jev。可以选择“稍后配置”，以后从“设置 → AI 服务”重新进入。引导中提供各平台申请入口，百炼接口地址已预填。

凭证抽查按以下服务顺序进行：

| 模型 | 官方说明与申请入口 | 软件内填写位置 |
| --- | --- | --- |
| 阿里百炼决策模型 | [模型说明与免费政策](https://help.aliyun.com/zh/model-studio/decision-model-preview#%E5%8D%8E%E5%8C%972-%E5%8C%97%E4%BA%AC-h4) · [百炼控制台](https://bailian.console.aliyun.com/) | “阿里百炼决策模型”页签，填写“百炼 API Key”和“决策接口地址”。 |
| TypeSafe Jev 决策模型 | [TypeSafe 官网](https://typesafe.ai/) · [API 控制台](https://console.typesafe.ai/) | “Jev（可选）”页签，填写“Jev API Key”；接口由程序处理，无需另外填写地址。 |

**百炼免费说明：** 截至 2026 年 11 月 12 日，官方页面标注 `decision-model-preview` 为“限时免费”，具体政策以官方页面和控制台为准。核实后勾选“我已确认该模型当前限时免费，启用百炼”；未勾选时不会调用百炼，也不会发送百炼连接测试。程序无法自动查询计费状态，免费条件变化后应取消勾选。

**百炼接口地址：** 软件默认提供以下北京试用地址，可用于快速体验：

```text
https://trial.cn-beijing.maas.aliyuncs.com/compatible-mode/v1/systemone
```

如使用自己的业务空间，请按[百炼决策模型 API 文档](https://help.aliyun.com/zh/model-studio/decision-model-api)获取对应地域的完整接口地址。北京地域格式如下，将 `{WorkspaceId}` 替换为自己的业务空间 ID 后，填入软件的“决策接口地址”：

```text
https://{WorkspaceId}.cn-beijing.maas.aliyuncs.com/compatible-mode/v1/systemone
```

保存配置后，可点击相应的“测试百炼连接（虚构内容）”或“测试 Jev（虚构内容）”检查连接。再进入“AI 尽调线索”，选择抽查科目，核对本次发送的数据预览并确认后，开始抽查。

**凭证抽查会发送所选范围内凭证的必要字段，例如科目、摘要、往来单位和金额，其范围与导入时的前 20 行样本不同。**

## 四、技术说明

DudLedger 采用 Python 开发，是使用本地 SQLite 账套的桌面工具。

| 部分 | 技术与实现 |
| --- | --- |
| 运行语言 | Python 3.11 及以上。 |
| 桌面界面 | Tkinter / ttk。 |
| 数据存储 | SQLite，本地保存账目、导入来源、关注备注和问题记录，无需单独安装数据库服务。 |
| 表格读取 | `openpyxl` 读取 `.xlsx` / `.xlsm`，`xlrd` 读取 `.xls`，CSV 由本地程序解析。 |
| AI 导入 | DeepSeek Flash 分析有限样本；本地规则、预检和模板配合完成导入。 |
| Agent 协作 | 随软件提供导入技能和本地命令入口，供 Agent 分析、校验并创建新账套。 |
| AI 凭证抽查 | 独立适配百炼决策模型、TypeSafe Jev 与 DeepSeek Flash，按审查问题返回判断结果。 |
| 密钥保存 | 优先使用系统安全凭据库；不可用时，仅在本次运行的内存中保留。 |

原始 Excel / CSV 文件不会因导入而被修改；账套保留来源、原行号和原行内容，方便追溯。金额以整数分存储，计算使用十进制处理。

日常查询、筛选、计算和备注在本机完成；启用云端 AI 功能时，按对应功能的范围发送数据。备份账套前，请先关闭该账套，再复制账套文件。

### 从源码运行

开发者或希望直接运行源码的用户，需要先安装 Python 3.11 或更新版本，并确保 Tkinter 可用。在项目目录中执行：

```bash
python -m venv .venv
```

激活环境：

```bash
# macOS / Linux
source .venv/bin/activate

# Windows PowerShell
.venv\Scripts\Activate.ps1
```

安装依赖并启动：

```bash
python -m pip install -e .
python run.py
```
