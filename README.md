# 法律尽调账簿浏览器（MVP）

把企业提供的明细账、序时账、科目余额表、资产负债表和利润表导入本地项目，逐层查看：**报表或科目 → 明细分录 → 同号凭证的已导入分录 → 关注与注释**。原始表格不会被修改。默认在本机处理；启用 AI 建议列（Jev 或 DeepSeek）或 Jev 法律尽调筛查并确认后，才会发送所选必要字段。

## 运行

需要 Python 3.11 或更新版本。macOS 和 Windows 均可运行源码版。

```bash
python -m venv .venv
# macOS: source .venv/bin/activate
# Windows: .venv\Scripts\activate
python -m pip install -e .
python run.py
```

运行依赖 `openpyxl`（`.xlsx/.xlsm`）、`xlrd`（旧版 `.xls`）、`typesafe-sdk`（Jev）和 `keyring`（系统钥匙串）。桌面界面采用 Python 自带的 Tk；数据使用本地 SQLite。当前提供源码运行方式，尚未制作经过验证的 `.app`、`.dmg` 或 Windows 安装包。

## 试用步骤

1. 启动后从顶部“文件”菜单选择“（批量）导入表格…”，先选表格即可。未打开账套时，会弹出保存窗口，显示建议的账套文件夹和文件名，可直接调整位置或名称；默认位置为 `~/Documents/DudLedger/账套`，同名时建议添加序号，已有账套不会被覆盖。所选文件夹会记住，也可从“设置 → 新账套默认文件夹…”调整。取消文件选择或账套保存窗口不会创建账套；已有账套时导入当前账套。也可通过“打开账套…”继续已有项目，或“在新账套中导入…”为另一企业打开新窗口。
2. 一次选择一个或多个文件，在同一个窗口勾选工作表，默认使用 Jev 给所有勾选的工作表建议表类型、表头和列。点“导入选中的工作表”后，一次确认预览发送范围，软件逐张处理并显示进度，成功且无警告的建议直接用于导入，无须逐张打开列设置。有警告或失败时暂停导入，按提示复核、重试或双击工作表手动调整。取消勾选 Jev 会提示自动识别可能有误，可双击手动调整列。现金流量表按工作表名称、文件名或开头的独立表名识别并自动略过，不列入待确认项、不提示；仅选择现金流量表时直接返回。“文件 → 导入记录”可管理已导入工作表并查看各表预检结论（旧版导入显示“无历史预检报告”），移除记录不会删除原始文件。
   正式写入前每张表都会整表预检：每一行都有去向（导入、排除并注明原因、待处理），拟导入行数与借贷合计一目了然；无法识别的金额、期间与日期矛盾、公式结果缺失（文件未保存计算缓存）、疑似漏掉的金额列等会集中列为疑点，按“原单元格 → 当前解释 → 问题原因 → 可选处理”展示，可排除所选行并重新预检。存在未解决的关键问题时该表暂停（不会偷偷跳过坏行），其他表照常导入。识别范围：表头不限于前 20 行；支持真实合并单元格的两层表头（区分期初/本期/本年累计/期末借贷）；结构一致的重复表头分区自动合并，结构变化的分区会明确提示；常见 CSV 编码（UTF-8、UTF-16、GBK/GB18030）与分隔符自动识别。成功导入的格式会保存为本地模板，下次遇到相同表头结构（不看文件名）优先套用，结构变化时重新按规则识别。“文件 → 导出导入质量报告…”可生成中文 Markdown 报告供事后核查。
3. 试用 `examples/模拟企业账簿.xlsx` 时，可一次导入其中的“序时账”和“科目余额表”两页。
4. 在“科目总览”点击左侧“展开 / 收起”列中的文字切换子科目，并双击科目，进入“明细账”；大类科目会带出其子科目分录。再双击一行查看凭证分录；可按期间筛选。余额表来源在顶部“文件 → 导入记录”窗口选择，不同期间的余额不会合并。科目树可全部展开、全部收起，或手动调整后在“更多”中点“记住当前展开”。
   科目总览、明细账的“更多”菜单和凭证窗口提供“选择显示列”；勾选即可显示或隐藏，也可“全部显示”或“恢复默认”。列设置保存在当前账套，隐藏列不会删除导入数据。偏好设置提供字体大小、滚动速度、表格虚线、凭证打开方式和账套首页选择。
5. 科目总览的搜索只查科目；明细账上方先显示当前科目范围，下一行集中放关键词、期间、查找和重置筛选。关键词可搜索科目、摘要、凭证号、往来单位、辅助项；点击日期、凭证、科目、摘要、借贷金额表头切换升降序，金额按数值排序。“更多 → 导出当前明细 CSV”使用当前科目、关键词、期间与排序，并导出全部匹配行。重置筛选保留科目范围，“显示全部科目”解除科目限制。
6. 如需跨表核对，从顶部“查看 → 核对提醒”打开独立窗口，点“设置核对范围”，指定会计年度/期间、参与的明细来源、余额表和报表来源，并为需要核对的报表项目勾选对应科目及借贷取值方向。保存后在该窗口查看金额、差额、口径和来源；差异只提示，不妨碍继续查看明细。
7. 在明细账双击分录进入凭证窗口，勾选“关注这张凭证”、写下注释并点“保存关注与注释”；关注的分录及凭证会显示浅红底色。“关注凭证”页可查找、直接修改注释、确认内容变化或取消关注；首次选择 MD 路径后，点“更新关注凭证 MD”会重建同一文件。MD 按科目提供索引，每张凭证正文只出现一次；软件外对该文件的手工修改会被覆盖。
8. 从顶部“查看”菜单打开“关联方名单”，可在当前账套手动新增名称、别名和备注。明细账的“用户标注关联方”列依据往来单位或辅助核算名称精确匹配；名称命中只是筛查线索，不代表法律上的关联关系已获证实。

### 报表到明细账

主界面保留“科目总览、明细账、资产负债表、利润表、关注凭证、AI 待核凭证”六页；核对提醒和导入记录仅从顶部菜单打开。默认收起次要列；已有账套保留之前保存的列偏好，需要切换新版默认时，在“选择显示列”中恢复默认。

资产负债表左右两侧、利润表均可单击项目名称进入明细账。优先使用当前报表来源及原行对应的已确认科目映射；否则唯一同名科目直接跳转并包含子科目。汇总项目或不能唯一对应的项目弹出科目选择窗口；“货币资金、营业收入、营业成本”会预选常见候选，由使用者确认。此选择只用于浏览，不改变核对口径，也不代表报表金额与明细合计一致。跳转会清除旧关键词和期间，明确显示“全部期间”，可再按需要筛选。

### AI 建议列（可选：Jev 或 DeepSeek）

在“偏好设置”选择建议列模型：默认 Jev（TypeSafe），也可选 DeepSeek（deepseek-flash，已关闭思考以降低延迟和费用）。两个模型分别输入对应的 API Key 并点“保存密钥”或“保存并完成”；密钥优先保存在系统安全凭据库，不写入账套或偏好文件；安全凭据库不可用时，仅在本次运行内存中保留并提示重启后重新输入。保存后输入框回显已保存的密钥（默认以 • 隐藏，勾选“显示明文”可查看原文）。批量导入默认勾选 AI 建议列；点击导入时会一次说明所有待处理工作表的发送范围与所用模型，供你确认或取消。每张表只发送前 20 行、每行最多 40 列、每格最多 60 字；这些内容可能包含企业名称和金额。不发送整份文件或本地路径。提示坚持“不影响使用就不打扰”：只有影响导入结果的情况才弹窗（导入校验不通过、借贷金额或期末余额只识别到一侧）；模型把两个字段指到同一列或超出范围时不再静默丢弃，会列出提示供核对，但允许继续；置信度只作内部排序依据，不显示成“导入准确率”。无提示时单表导入直接填入不再弹窗，批量导入满足校验且无此类提示即统一自动导入。有提示或失败时暂停，允许统一查看、重试或只手动调整个别工作表。手动保存的列设置不会被批量建议覆盖。也可取消勾选 AI，软件会提示本地自动识别可能有误，仍可手动修改。匹配顺序为：已确认模板 → 本地规则 → AI 建议 → 人工调整；所有结果都经过同一套本地校验与整表预检。

### Jev 法律尽调筛查

1. 在“设置 → Jev 审查”保存 API Key；“测试连接”只发送固定虚构内容。密钥适用于所有账套；规则、展示档位、批次和人工复核意见按账套隔离。
2. 打开“AI 待核凭证”，点“核查全部凭证”。默认覆盖当前账套所有已导入明细，不受科目、期间、关键词筛选和明细界面显示条数限制。
3. 在“使用 Jev 云端辅助审查”窗口核对账套、范围、条数、字段、关联方名单及逐页发送预览，点“确认并开始审查”。取消不发送数据。每张凭证只发送日期、科目、摘要、往来单位、辅助核算（有内容时）及非零一侧的借贷金额；凭证内内容相同的行由本地合并金额并标注次数，共用字段只发送一次；原始文件、路径、文件名、制单人、原始行及凭证标识留在本地。当前账套的关联方名单（名称与别名，不含备注）会随每张凭证一并发送，用于含简称的关联方匹配；名单可在“查看 → 关联方名单”维护或批量导入（粘贴每行一个名称，或从 Excel/CSV/TXT 导入第一列）。名单在预览后发生变化时需重新预览确认。结转损益凭证按整张摘要、科目组合及借贷平衡保守识别后跳过，显示跳过数量；混有其他业务或描述不明确时继续核查。
4. 进度条实时显示已处理凭证数、百分比、成功、失败及结转损益跳过数量；完成一张即可查看。不再使用加权平均打分：**任一类主题概率达到档位阈值，整张凭证即列为问题凭证并按命中主题自动分类**。三档阈值为主题概率：宽松 ≥0.65、中 ≥0.50、谨慎 ≥0.35（数值越高报得越少）；0.35～0.65 之间的主题标注“待确认”。待核列表保留命中凭证及信息不足、判断不确定或分段核查的凭证；结果按命中概率降序、同币种金额作次级排序，高额退费、退资等结合金额由律师人工判断。历史批次、科目、主题和期间筛选收在“更多选项”。切换档位只查询本地，不重新请求。概率按未四舍五入值筛选，展示一位小数；新版按凭证整体判断；长凭证分段时各主题信号分别取片段最大值，并保留原始片段回答及人工复核标记。金额是所展示分录的最大单边绝对值，不是借贷合计；不同币种分别显示。
5. “更多选项”中的“信息不足／判断不确定”和“分析失败／未分析／过期”有独立入口，不随三档阈值隐藏。“全部（含未命中）”便于抽查漏检。这些筛选旁的数量是**当前批次的分录数量**，主进度条按凭证计数，不能据此认定范围以外的账簿已经审查。
6. 双击结果，查看该批次分录快照、来源行、结构化判断、命中概率、随附关联方名单、核查建议、模型与规则版本。点“打开本地同号凭证／加入关注”，查看本地其他分录并按原有流程关注；这些额外分录不会自动发送。人工复核可标为“待核／需补材料／已核查无异常／继续关注”并填写备注。
7. 普通凭证精简、合并去重后只发一次请求，固定一套 11 个问题（十类主题 Noul＋一个信息不足 Noul）。超长凭证或摘要按预算分段，无静默截断；服务仍报告超长时继续拆小，无法处理则明确标为失败。审查可取消，已完成结果保留；正在发出的请求需要结束后才能停止。每个账套同时一个批次，全应用最多四个 Jev 请求。网络、限流和暂时性服务错误最多尝试三次，认证失败停止后续请求。
8. 停止或失败后，再点“核查全部凭证”，按账套的**当前全部数据**生成新预览，重新确认后开始；同一凭证本次选定的全部输入、关联方名单、规则版本及模型完全相同的已完成结果可复用。规则修改形成新版本；重新导入、移除来源、输入或关联方名单变化会使旧结果失效，人工备注仍保留。旧账套自动升级到 v6，并保留分录、关注记录及原文件。

同一“年度＋期间＋凭证字＋凭证号”的选定分录合并为一次请求；缺少期间时沿用日期归并，无凭证号按来源行单列。每张凭证返回十个主题 Noul 和一个信息不足 Noul 的独立概率，不再有五级优先分；历史批次的旧优先分结果仍可查看；首版固定 `jev-1.13.0`，不另外生成法律报告。**主题概率不代表违法概率或最终法律结论**。默认提示词及阈值尚未完成律师标注后的中文效果校准，可在“审查规则”编辑提问、核查建议和三个阈值，或恢复默认；历史结果保留原版本。

已有 72 条虚构样例和离线指标统计工具。实际接入流程与待完成的校准步骤见 [Jev 筛查实施与验证](docs/Jev筛查实施与验证.md)；完整设计见 [功能计划](docs/Jev法律尽调筛查功能计划.md)。

### 已使用旧版导入过同一工作表

关闭软件后重新运行，打开原来的 `.sqlite` 账套，再导入同一个 Excel 工作表。映射窗口现在有“会计年度”“期间”等字段。确认后若提示来源已存在，选择“是”即可**替换该工作表的旧导入记录**；原始 Excel 不会修改，替换失败会保留旧记录。旧账套会自动增加新字段，但旧分录中缺失的凭证号、期间等信息需要重新导入才能补齐。

对于“日期、会计年度、期间、凭证字、凭证号、摘要、科目编码、科目全名、核算维度、币别、原币金额、借方金额、贷方金额、制单”这种序时账，全部 14 列均可单独映射；没有“往来单位”列时应保持“不导入”。同一凭证后续分录的日期和凭证号留空时，导入器会在连续数据行内继承上一行凭证标识，并保留每行原始内容供核对。

多份余额表是不同时间点的快照，“科目余额”页一次只显示所选的一份，不会把几个月的期末余额相加。“明细账”中的期间筛选也作用于辅助核算和导出；余额表与明细是否覆盖同一期间仍需人工确认。

跨表核对只使用所选来源及期间。余额表本期借贷与明细逐科目比较；资产负债表项目与所选科目的期末余额比较；利润表项目与所选科目的期间发生额比较。报表项目可能汇总多个科目，必须由使用者确认对应关系；空白金额、缺失科目或失效来源标为“待核”，不当作零值或账务错误。重新导入后，如果关注凭证内容发生变化或原凭证无法匹配，标注会保留供复核，暂不写入 MD。

支持 `.xlsx`、`.xlsm`、`.xls` 和 UTF-8 CSV。余额表既支持借贷分列，也支持“余额金额＋余额方向”格式；两行表头可分别识别期初、本期发生、本年累计和期末的借贷列。核算维度明细行不计入科目合计，避免重复相加。资产负债表可识别双侧表头，利润表最多保留三列金额。无法可靠识别的版式仍需逐张校对。公式单元格需要原文件保存了计算结果；如果预览为空，请先在 Excel 中重新计算并保存副本。

## 当前能力与边界

| 模块 | 已实现 | 需要留意 |
|---|---|---|
| 导入 | `.xls/.xlsx/.xlsm/CSV`、多文件工作表自动分类、双层余额表表头、预览与手工映射、默认批量 Jev 列建议、原行号及 SHA-256 留痕；重复来源可事务性替换 | 现金流量表自动略过且不提示；无 Jev 时不能可靠分类的表需手动设置；有警告的 Jev 建议需复核；多文件期间重叠不自动去重 |
| 浏览 | 可展开科目树及父科目穿透、明细、凭证分录；虚线表格与温和的借贷区别；三处表格可分别设置显示列；报表项目穿透明细；页内搜索、期间筛选及表头排序；CSV 导出；余额表来源选择 | “凭证”按会计年度＋期间＋凭证字＋凭证号重组，缺少期间时按日期；并非原始凭证图片 |
| 核对 | 余额滚动、所选余额表与明细本期发生额、确认映射后的报表项目比较、凭证借贷、跨文件疑似重复 | 需人工确认期间、来源和报表项目对应科目；范围不全时标为“待核” |
| 关注凭证 | 账套内标注与多行注释、按科目索引的一键 MD 更新 | 凭证是根据已导入明细重组的，内容变化后需复核再导出 |
| 关联方 | 当前账套手动维护名称、别名和备注，支持粘贴与 Excel/CSV/TXT 批量导入；明细与 CSV 标示精确匹配结果；名称与别名随 AI 审查发送云端 | 不从摘要或模糊包含关系推定关联方身份；备注不发送 |
| Jev 尽调筛查 | 完整范围快照、逐页隐私确认、十类主题命中分类（无加权打分）、三档阈值、异常与不确定入口、规则版本及人工复核 | 云端功能须主动确认；中文效果与默认阈值尚待校准 |
| 数据 | 本地 SQLite，金额按分存储，原文件不改动 | 未提供文件加密和用户权限；请按案件保密要求保管账套与源文件 |

如果企业仅提供某一科目的明细，点开凭证时可能缺少其他科目分录；“核对提醒”会提示这种可能。没有凭证号的行无法可靠归并为一张凭证。科目名称和编码不一致、父级与明细级科目同时出现在余额表时，使用者需要确认科目级次和统计范围。

## 技术选型与模块

- `ledger_viewer/importer.py`：解析文件、字段映射、金额与日期标准化。
- `ledger_viewer/store.py`：本地数据模型和只读查询；导入操作作为单个事务，失败则回滚。
- `ledger_viewer/checks.py`：独立核对规则，只输出差异，不修改数据。
- `ledger_viewer/reconciliation.py`：按用户确认的来源、期间和项目映射比较报表与账簿。
- `ledger_viewer/voucher_notes.py`：保存关注凭证及注释，生成按科目索引的 MD。
- `ledger_viewer/related_parties.py`：按用户维护名单对往来单位和辅助核算作精确匹配；名单扁平化及批量导入解析。
- `ledger_viewer/jev_mapping.py`：在用户确认发送预览后，让 Jev 从有限候选列中提出建议；密钥由系统钥匙串保管。
- `ledger_viewer/grid_lines.py`：为可滚动表格绘制浅色虚线分隔。
- `ledger_viewer/ui.py`：桌面窗口；不承担会计计算。
- `ledger_viewer/analysis_api.py`：只读分页分录接口及关键词候选接口；完整筛查不使用 5,000 行关键词候选上限。
- `ledger_viewer/jev_rules.py`、`jev_review.py`、`jev_ui.py`：版本化规则、确认快照与后台批次、结果与复核界面。
- `ledger_viewer/jev_runtime.py`：共用 Jev 请求并发限制。
- `ledger_viewer/jev_calibration.py`：离线统计人工标注样例的召回、误报、低分漏检与未完成数量。

下一阶段继续适配其他真实企业样表（可脱敏）：更复杂的多行表头、合并单元格、金蝶/用友不同列名、辅助核算单独表、借贷方向其他表示法和分月文件覆盖范围。Jev 已支持“借款与实缴出资”等核查主题；下一步由律师标注虚构样例、单独验证默认规则及阈值，并继续保持账面事实、模型判断和待补证据的区分。
