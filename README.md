# 法律尽调账簿浏览器（MVP）

把企业提供的明细账、序时账和科目余额表导入本地账套，以只读方式逐层查看：**科目余额 → 明细分录 → 同号凭证的已导入分录**。原始表格不会被修改，也不会上传到服务器。

## 运行

需要 Python 3.11 或更新版本。macOS 和 Windows 均可运行源码版。

```bash
python -m venv .venv
# macOS: source .venv/bin/activate
# Windows: .venv\Scripts\activate
python -m pip install -e .
python run.py
```

主程序只有 `openpyxl` 一个第三方运行依赖。桌面界面采用 Python 自带的 Tk；数据使用本地 SQLite。当前提供源码运行方式，尚未制作经过验证的 `.app`、`.dmg` 或 Windows 安装包。

## 试用步骤

1. 启动后点“新建账套”，选择本地 `.sqlite` 文件的保存位置。每个项目/企业建议单独建账套。
2. 点“导入 Excel/CSV”，先导入 `examples/模拟企业账簿.xlsx` 的“序时账”页，类型选 `entry`。检查表头、列映射后导入。
3. 再导入同一文件的“科目余额表”页，类型选 `balance`。
4. 在“科目余额”双击科目，再在“明细账”双击一行查看凭证分录。查看“辅助核算”“核对结果”“来源文件”。
5. 可按关键词搜索科目、摘要、凭证号、往来单位、辅助项；可导出全部或当前科目的明细 CSV。

支持 `.xlsx`、`.xlsm`、UTF-8 CSV。旧版 `.xls` 请先在 Excel 中另存为 `.xlsx`。余额表既支持借贷分列，也支持“余额金额＋余额方向”格式。导入前可手工指定表头行和列映射。公式单元格需要原文件保存了计算结果；如果预览为空，请先在 Excel 中重新计算并保存副本。

## 当前能力与边界

| 模块 | 已实现 | 需要留意 |
|---|---|---|
| 导入 | 表头猜测、预览、手工映射、CSV/XLSX、多工作表、原行号及 SHA-256 留痕 | 不自动识别所有厂商导出格式；多文件期间重叠不自动去重 |
| 浏览 | 科目、明细、凭证分录穿透；搜索；辅助核算汇总；CSV 导出 | “凭证”是用已导入分录按日期＋凭证字＋凭证号重组，并非原始凭证图片 |
| 核对 | 余额滚动、余额表与明细本期发生额、凭证借贷、跨文件疑似重复 | 范围不全时标为“待核”，不能直接认定账务错误 |
| 数据 | 本地 SQLite，金额按分存储，原文件不改动 | 未提供文件加密和用户权限；请按案件保密要求保管账套与源文件 |

如果企业仅提供某一科目的明细，点开凭证时可能缺少其他科目分录；“核对结果”会提示这种可能。没有凭证号的行无法可靠归并为一张凭证。科目名称和编码不一致、父级与明细级科目同时出现在余额表时，使用者需要确认科目级次和统计范围。

## 技术选型与模块

- `ledger_viewer/importer.py`：解析文件、字段映射、金额与日期标准化。
- `ledger_viewer/store.py`：本地数据模型和只读查询；导入操作作为单个事务，失败则回滚。
- `ledger_viewer/checks.py`：独立核对规则，只输出差异，不修改数据。
- `ledger_viewer/ui.py`：桌面窗口；不承担会计计算。
- `ledger_viewer/analysis_api.py`：后续 AI 分析使用的只读候选数据接口，返回源文件哈希和行号。关键词命中仅是线索。

下一阶段优先适配真实企业样表（可脱敏）：多行表头、合并单元格、金蝶/用友常见列名、辅助核算单独表、借贷方向不同表示、分月文件覆盖范围。之后再增加“借款与实缴出资”等专题分析；每条提示需链接原始账簿行，并区分账面事实、规则推断和待补证据。

## 验证与打包

```bash
python -m unittest discover -s tests -v
```

需要发给没有 Python 的同事时，可在各自操作系统上用 PyInstaller 打包；当前版本未验证安装包，建议先用源码版和脱敏账簿试用。
