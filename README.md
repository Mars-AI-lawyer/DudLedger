# 法律尽调账簿浏览器（MVP）

把企业提供的明细账、序时账、科目余额表、资产负债表和利润表导入本地项目，逐层查看：**查看账表 → 框选或勾选 → 批量关注／归入问题 → 双击凭证**。原始表格不会被修改。默认在本机处理；导入 AI 建议列仅用 DeepSeek Flash，发送本地定位的表头；凭证尽调筛查仍使用 Jev，须另行确认其发送范围。

## 运行

需要 Python 3.11 或更新版本。macOS 和 Windows 均可运行源码版。

```bash
python -m venv .venv
# macOS: source .venv/bin/activate
# Windows: .venv\Scripts\activate
python -m pip install -e .
python run.py
```

运行依赖 `openpyxl`（`.xlsx/.xlsm`）、`xlrd`（旧版 `.xls`）、`typesafe-sdk`（Jev）和 `keyring`（系统钥匙串）。桌面界面采用 Python 自带的 Tk；数据使用本地 SQLite。当前提供源码运行方式，尚未制作经过验证的 `.app`、`.dmg` 或 Windows 安装包。

## 试用步骤

1. 启动后从顶部“文件”菜单选择“（批量）导入表格…”，先选表格即可。未打开账套时，会弹出保存窗口，显示建议的账套文件夹和文件名，可直接调整位置或名称；默认位置为 `~/Documents/DudLedger/账套`，同名时建议添加序号，已有账套不会被覆盖。所选文件夹会记住，也可从“设置 → 新账套默认文件夹…”调整。取消文件选择或账套保存窗口不会创建账套；已有账套时导入当前账套。也可通过“打开账套…”继续已有项目，或“在新账套中导入…”为另一企业打开新窗口。
2. 一次选择一个或多个文件，在同一个窗口勾选工作表，默认使用 DeepSeek Flash 给所有勾选的工作表建议表类型和列。点“导入选中的工作表”后，软件仅发送本地定位的表头，逐张处理并显示进度，成功且无警告的建议直接用于导入，无须逐张打开列设置。有警告或失败时暂停导入，按提示复核、重试或双击工作表手动调整。取消勾选 AI 会提示自动识别可能有误，可双击手动调整列。现金流量表按工作表名称、文件名或开头的独立表名识别并自动略过，不列入待确认项、不提示；仅选择现金流量表时直接返回。左下“账套 → 导入记录”可管理已导入工作表并查看各表预检结论（旧版导入显示“无历史预检报告”），移除记录不会删除原始文件。
   正式写入前每张表都会整表预检：每一行都有去向（导入、排除并注明原因、待处理），拟导入行数与借贷合计一目了然；无法识别的金额、期间与日期矛盾、公式结果缺失（文件未保存计算缓存）、疑似漏掉的金额列等会集中列为疑点，按“原单元格 → 当前解释 → 问题原因 → 可选处理”展示，可排除所选行并重新预检。存在未解决的关键问题时该表暂停（不会偷偷跳过坏行），其他表照常导入。识别范围：表头不限于前 20 行；支持真实合并单元格的两层表头（区分期初/本期/本年累计/期末借贷）；结构一致的重复表头分区自动合并，结构变化的分区会明确提示；常见 CSV 编码（UTF-8、UTF-16、GBK/GB18030）与分隔符自动识别。成功导入的格式会保存为本地模板，下次遇到相同表头结构（不看文件名）优先套用，结构变化时重新按规则识别。“文件 → 导出导入质量报告…”可生成中文 Markdown 报告供事后核查。
3. 试用 `examples/模拟企业账簿.xlsx` 时，可一次导入其中的“序时账”和“科目余额表”两页。
4. 在“科目总览”点击左侧“展开 / 收起”列中的文字切换子科目，并双击科目，进入“明细账”；大类科目会带出其子科目分录。再双击一行查看凭证分录；可按期间筛选。余额表来源在顶部左下“账套 → 导入记录”窗口选择，不同期间的余额不会合并。科目树可全部展开、全部收起，或手动调整后在“更多”中点“记住当前展开”。
   科目总览、明细账的“更多”菜单和凭证窗口提供“选择显示列”；勾选即可显示或隐藏，也可“全部显示”或“恢复默认”。列设置保存在当前账套，隐藏列不会删除导入数据；明细账“关注”列显示在最后，已有账套保留其显示或隐藏状态。偏好设置提供字体大小、滚动速度、表格虚线、凭证打开方式和账套首页选择。
5. 左侧导航默认显示图标，鼠标停留后可查看功能名称。点工作区左上角的侧栏图标展开文字或折叠回图标，也可用“查看 → 切换侧栏”。“问题工作台”和“计算器”固定放在左侧，打开计算器也保留导航。两者共用右侧区域；工作台可展开为独立窗口，与计算器同时使用。顶部只保留页面标题、账套名称和导入入口。
   明细账顶部输入关键词后按回车，可查找科目、摘要、凭证号、往来单位和辅助项。点可筛选表头右侧的小箭头，可按日期或多个自然月、摘要文字、金额大小等条件筛选。点列名可沿用原有排序。“更多 → 筛选条件”也能编辑会计期间和隐藏列。“清除全部筛选”保留科目范围和排序，CSV 导出包含全部匹配行。
6. 如需跨表核对，从顶部“查看 → 核对提醒”打开独立窗口，点“设置核对范围”，指定会计年度/期间、参与的明细来源、余额表和报表来源，并为需要核对的报表项目勾选对应科目及借贷取值方向。保存后在该窗口查看金额、差额、口径和来源；差异只提示，不妨碍继续查看明细。
7. 明细账点击“关注所选（N）”直接关注，不强制打开备注；双击凭证后可写备注。关注的分录显示浅红底色。“关注凭证”页显示日期、凭证号、摘要、金额、中文科目、备注与复核状态；单选后展开“编辑备注”，多选时收起编辑区。MD 更新及另存、批量取消关注和确认变更位于“更多”；取消关注会集中提示备注影响。MD 按科目提供索引，每张凭证正文只出现一次，外部手工修改会被下一次更新覆盖。
8. 从顶部“查看”菜单打开“尽调主体名单”，可在当前账套手动新增名称、身份（股东、实控人、董监高、关联企业等，可多选）、与目标公司关系、别名和备注；批量导入支持“名称｜股东,董事”或文件第二列身份。明细账的“用户标注关联方”列依据往来单位或辅助核算名称精确匹配；名称命中只是筛查线索，不代表法律上的关联关系已获证实。

### 大账套浏览与操作保护

明细账和 AI 线索列表每页显示 500 条，可用“上一页／下一页”继续浏览，并显示匹配总数。改变筛选或排序会回到第一页；翻页清除当前框选，已加入计算器的记录保持不变；明细账的凭证勾选跨页保留，并显示跨页张数。改变搜索、筛选、科目、排序或账套会清空勾选。选区统计只包含当前页，导出 CSV 包含全部匹配行。

大账套的明细查询、科目汇总、核对与 AI 本地预览在后台处理；查找科目、切换余额表来源只刷新科目总览。AI 审查的进度变化合并更新，隐藏页面时保留任务状态，返回后读取最新结果。小窗口或大字体下，筛选与操作栏自动换行。

较大文件的工作表识别、表头预览、整表预检和写入在本机后台运行。点击“停止”会保留已完成的工作表，当前尚未完成的工作表回滚。失败项保留列设置和具体原因，可直接重试；成功项标记完成并取消勾选。预检后原文件发生变化时，该工作表不会写入，须重新预检。

问题描述、核查笔记和凭证关注备注停止输入约 800 毫秒后自动保存；切换、关闭或退出账套前会完成保存。保存失败会保留窗口及编辑内容，并阻止丢弃。关注列表、普通凭证窗口和 AI 线索详情共用备注同步；多个入口同时修改发生冲突时保留各自输入，可点“重读已保存备注…”先复制当前输入再核对最新内容。展开／收起子科目后，当前选区合计及时更新，已加入计算器的历史记录不变。

账套启用 SQLite WAL 以支持后台读取与写入。需要直接复制账套文件备份时，先关闭对应账套；应用运行中仍可能存在配套的 `-wal` 文件。

测试范围、性能记录和复测命令见 [流畅度与交互优化验证](docs/流畅度与交互优化验证.md)。

### 报表到明细账

主界面保留“科目总览、明细账、财务报表、关注凭证、AI 尽调线索”五页。“财务报表”内以分段按钮切换资产负债表／利润表，各自保留报表来源、滚动位置和计算记录。报表科目单击或双击均不跳转，框选金额即可合计及复制。导入记录与核对提醒从左下“账套”菜单打开，也保留原生菜单入口。已有账套的列偏好继续有效，可在“选择显示列”中恢复默认。

### 表头识别导入与保密范围

导入识别统一使用 DeepSeek Flash（`deepseek-flash`，低思考）；旧的 Jev 或逐层识别偏好自动转为此方式。表头先在本地定位，多层表头合并为一行后再发送：**每张表仅 1 行逻辑表头、最多 40 列、每格 60 字**。不发送业务样本、疑点行、文件名、真实工作表名或路径。表头自身仍可能包含使用者写入的敏感文字，导入前可在本地核对。无法可靠定位时提示手动填写表头，不自动扩大云端读取范围。

DeepSeek 密钥在“偏好设置”保存，优先使用系统安全凭据库，凭据库不可用时只保留在本次运行内存。保存密钥后，AI 建议列不再逐次弹窗；也可取消 AI，改用本地规则或手动映射。完整账簿的读取、整表预检、疑点行处理及账套写入都在本机完成；无法安全处理的疑点交回人工。手动保存的列设置仍优先，不被批量建议覆盖。

需要外部 Agent 协助时，可自行点击“复制给我的 Agent”。任务包含本机路径，外部 Agent 的模型可能接收它读取的原始内容，其读取范围与内置的表头请求不同。Agent 使用随软件提供的导入技能，复用本地解析与整表预检，创建新账套且不覆盖已有账套。详见 [表头识别导入与 Agent 接手](docs/三层Excel导入与Agent接手.md)。

### 选格复制与加减计算

科目余额表（“科目总览”）、明细账、资产负债表、利润表和凭证窗口均支持类似 Excel 的矩形框选：按住鼠标拖过一段或多列单元格，表格底部立即显示合计、计数与金额项数，计算侧栏收起时也能查看。计数按非空格统计，合计仅计算选区中的金额列，科目编码、日期等不作为金额相加；空白格忽略。拖至表格边缘可自动滚动继续选，Shift+单击或 Shift+方向键可扩展选区，排序或筛选后清除旧选区。

用 **Ctrl+C**（Mac 同时支持 **⌘C**）复制选区，再在其他软件用普通粘贴快捷键粘贴，多格保留行列结构。支持摘要、日期、凭证、金额、来源等可见列，按当前显示列序复制；含换行的摘要会保留在原格内。没有单独的复制按钮。双击明细仍打开凭证。拖动表头列分隔线仍可调整列宽，列宽拖动与单元格框选分别处理，调整列宽时保留当前选区。

科目余额表可框选期初、本期、本年累计与期末的借贷金额，科目编码和明细行数不计入金额合计。按当前展开的可见科目行选取，收起的子科目不进入选区；父级和子级若同时选中，则按所选格子分别相加。余额表计算记录保留当时的来源选择与科目信息。

需要跨选区做加减时，点击左侧“计算器”展开右侧侧栏，上方“当前选区”同步显示金额项数、计数和合计，下方“累计结果”保持独立。框选一段后点“＋ 加入”或“－ 减去”，整段金额才记入计算；重新框选只更新当前预览，不会改变累计结果，也不会自动展开侧栏。

计算过程按“选区 A、B、C……”逐项列出符号、金额项数和合计。点击记录，在下方查看当时各金额格的原文字、列名与来源（余额表显示来源选择与科目，明细和凭证显示原行）；已加入的金额和来源固定为本次窗口内的快照，后续排序、筛选或数据变化不会重算历史记录。“撤销上一步”整段撤回，“清空”清除累计记录并保留当前选区预览。预览合计与累计结果均可选中文字后 Ctrl+C／⌘C 复制，没有独立复制按钮。

计算在本地完成，使用十进制金额，不修改账簿。侧栏收起再展开保留本窗口记录；小凭证窗口展开时会适当增高，收起后恢复；若手动调整窗口大小则保留调整。主窗口的科目总览、明细账、资产负债表与利润表分别保留计算记录；切到其他页面时显示最近使用的计算来源。独立凭证窗口另行计算。关闭窗口或退出账套后不保留计算记录。不同币种与单位由使用者核对。

### 律师尽调问题工作台

点击左侧“问题工作台”展开或收起。右侧上方为可搜索的问题列表，中间为当前问题的凭证表，下方为可折叠的问题描述和核查笔记。问题显示名称、状态与凭证数；凭证直接显示日期、凭证号、摘要、金额和复核状态。单击只选中凭证，不替换问题编辑区；双击打开凭证。没有预览模块。

- 明细账、关注凭证和工作台凭证表的行首是“勾选框＋⋮⋮ 拖曳手柄”。普通单元格用于框选复制；明细账还能合计。Shift 点击勾选框连续选择，表头勾选或“本页全选”只操作当前页。
- 批量操作优先使用勾选凭证；没有勾选时使用框选区域涉及的凭证；都没有时使用当前行。同一凭证多条分录去重，按钮及右键显示张数。明细账的勾选跨页保留，选择栏可一键清空。
- 从已选凭证的手柄拖动整组，从未选凭证的手柄只拖该张。拖到问题名称或当前问题的凭证表建立关联；无目标问题时松开选择问题。也可右键或点击“加入问题…”。拖到右边缘停留展开工作台，Esc 或无效投放取消。
- 同张凭证可归入多个问题；跨问题拖曳增加关联。加入问题自动关注；取消关注保留问题关联；移除关联或删除问题保留关注。批量加入和批量关注失败时整批回滚，重复操作不覆盖备注或确认内容变化。
- 侧栏“独立窗口”打开可移动到第二屏的大窗口：左侧问题列表，右上凭证表，右下问题笔记。“停靠右侧”返回；空间不足以保留至少 520 像素主表宽度时自动独立显示。关闭独立窗口只收起工作台，从左侧入口可唤回。切换前保存草稿，保存失败保留输入并阻止切换。
- 金额来自已导入分录：借贷相等显示单边合计；不相等显示“借 ××／贷 ××”并提示“已导入借贷不一致”，不将两边相加。不同日期显示范围，摘要去重合并，悬停查看全文。原币不混入本位币金额合计。
- 问题凭证每次显示 100 张，点“加载更多”继续。归集快照永久保存在当前账套；原凭证未匹配时双击打开只读快照。更多菜单可查看所选归集快照、确认已复核、批量移除关联或加入其他问题。凭证备注在关注页或凭证窗口编辑。

第一版不包含独立索证清单、AI 自动归类或按问题导出。关注凭证 MD 导出继续使用原有方式。

### Jev 法律尽调凭证筛选

目标是高召回：从几十万行明细中筛出值得律师查看的凭证并按尽调主题分类，AI 不做法律定性，也不输出“高风险/低风险”。

1. 在“设置 → Jev 审查”保存 API Key；“测试连接”只发送固定虚构内容。密钥适用于所有账套；规则、展示档位、批次和人工复核意见按账套隔离。“审查规则与尽调筛选设置”中可编辑金额关注线、净资产/总资产/营业收入关注比例（1%/0.5%/0.5%）与科目分位线（P95/P99）。**金额关注线默认不设**：不在设置中填写即完全关闭，任何金额都不触发“达到金额关注线”特征；需要时可手动填写固定金额，达到即标注特征并使机械凭证恢复送审。各占比基数自动取最新资产负债表/利润表，可手动覆盖。这些是律师筛选参数，不是审计重大性标准。
2. 打开“AI 尽调线索”，点“筛选全部凭证”。默认覆盖当前账套所有已导入明细，不受科目、期间、关键词筛选和明细界面显示条数限制。
3. 在“使用 Jev 云端辅助审查”窗口核对账套、范围、条数、字段、尽调主体名单及逐页发送预览，点“确认并开始审查”。取消不发送数据。每张凭证只发送日期、科目、摘要、往来单位、辅助核算（有内容时）及非零一侧的借贷金额；凭证内内容相同的行由本地合并金额并标注次数，共用字段只发送一次；原始文件、路径、文件名、制单人、原始行及凭证标识留在本地。随每张凭证一并发送的还有：按身份分组的尽调主体名单（名称、别名与身份，不含备注）和程序预计算的“程序特征”（命中主体名单、摘要关键词线索、金额关注线与占净资产/总资产/营业收入比例、科目单笔金额分位、交易对手金额排名）——程序只陈述事实，比例与排名不由模型推算。名单可在“查看 → 尽调主体名单”维护或批量导入。名单在预览后发生变化时需重新预览确认。结转损益、计提折旧摊销、汇兑自动结转等机械凭证按整张摘要、科目组合及借贷平衡保守识别后跳过送审（保留在“低价值未送审”中可查看）；一旦命中主体名单、摘要线索或达到金额关注线，自动恢复送审。
4. 进度条实时显示已处理凭证数、百分比、成功、失败及低价值跳过数量；完成一张即可查看。**任一分类或整体判断概率达到“谨慎”档（≥0.35）即进入待核线索**；结果页顶部按十三个尽调分类（股权与资本、关联方与特殊资金往来、借款与融资、担保/抵押/质押、对外投资与并购、重大合同与重大交易、重大资产、知识产权与研发、劳动与人员、政府/补助/监管、诉讼与争议、异常应收/预付/往来、其他尽调线索）显示数量，点击即筛选。一张凭证可同时进入多个分类，分类来源标注“规则/Jev/用户”。查看优先级取代风险等级：概率 ≥0.65 为“优先查看”、≥0.50 为“建议查看”、≥0.35 为“一般线索”，这是尽调相关程度，不是法律风险评级。待核列表保留命中凭证及信息不足、判断不确定或分段核查的凭证；历史批次、科目、期间筛选收在“更多选项”。切换档位只查询本地，不重新请求。概率按未四舍五入值筛选，展示一位小数；按凭证整体判断；长凭证分段时各分类信号分别取片段最大值，并保留原始片段回答及人工复核标记。金额是所展示分录的最大单边绝对值，不是借贷合计；不同币种分别显示。
5. “更多选项”中的“信息不足／判断不确定”和“分析失败／未分析／过期”有独立入口，不随三档阈值隐藏。“全部（含未命中）”便于抽查漏检。这些筛选旁的数量是**当前批次的分录数量**，主进度条按凭证计数，不能据此认定范围以外的账簿已经审查。
6. 双击结果，查看分录快照、来源行、关注依据（程序特征事实）、分类勾选、整体判断概率、核查建议、模型与规则版本。可勾选增删尽调分类（记录为用户调整，可改回）、勾选“忽略此线索”（从待核列表隐藏，仅保存反馈供后续优化，不自动训练）、点“打开本地同号凭证／加入关注”按原有流程关注。人工复核可标为“待核／需补材料／已核查无异常／继续关注”并填写备注。
7. 普通凭证精简、合并去重后只发一次请求，固定一套 15 个问题（十三个尽调分类 Noul＋整体“是否值得律师查看”Noul＋一个信息不足 Noul）。系统提示词定位为“凭证筛选助手”：只判断是否值得律师进一步查看，不得推断抽逃出资、利益输送、违法担保等法律结论；宁可多报，由律师排除。超长凭证或摘要按预算分段，无静默截断；服务仍报告超长时继续拆小，无法处理则明确标为失败。审查可取消，已完成结果保留；正在发出的请求需要结束后才能停止。每个账套同时一个批次，全应用最多四个 Jev 请求。网络、限流和暂时性服务错误最多尝试三次，认证失败停止后续请求。
8. 停止或失败后，再点“核查全部凭证”，按账套的**当前全部数据**生成新预览，重新确认后开始；同一凭证本次选定的全部输入、关联方名单、规则版本及模型完全相同的已完成结果可复用。规则修改形成新版本；重新导入、移除来源、输入或关联方名单变化会使旧结果失效，人工备注仍保留。旧账套自动升级到 v6，并保留分录、关注记录及原文件。

同一“年度＋期间＋凭证字＋凭证号”的选定分录合并为一次请求；缺少期间时沿用日期归并，无凭证号按来源行单列。每张凭证返回十三个分类 Noul、一个整体判断 Noul 和一个信息不足 Noul 的独立概率；历史批次的旧十类主题结果仍按原规则查看；首版固定 `jev-1.13.0`，不另外生成法律报告。**分类与优先级不代表违法概率、法律风险等级或最终法律结论**。默认提示词及阈值尚未完成律师标注后的中文效果校准，可在“审查规则与尽调筛选设置”编辑提问、核查建议、三个阈值和金额关注参数，或恢复默认；历史结果保留原版本。

已有 72 条虚构样例和离线指标统计工具。实际接入流程与待完成的校准步骤见 [Jev 筛查实施与验证](docs/Jev筛查实施与验证.md)；完整设计见 [功能计划](docs/Jev法律尽调筛查功能计划.md)。

### 已使用旧版导入过同一工作表

关闭软件后重新运行，打开原来的 `.sqlite` 账套，再导入同一个 Excel 工作表。映射窗口现在有“会计年度”“期间”等字段。确认后若提示来源已存在，选择“是”即可**替换该工作表的旧导入记录**；原始 Excel 不会修改，替换失败会保留旧记录。旧账套会自动增加新字段，但旧分录中缺失的凭证号、期间等信息需要重新导入才能补齐。

对于“日期、会计年度、期间、凭证字、凭证号、摘要、科目编码、科目全名、核算维度、币别、原币金额、借方金额、贷方金额、制单”这种序时账，全部 14 列均可单独映射；没有“往来单位”列时应保持“不导入”。没有借贷分列的序时账可改用“金额（单列）”＋“借贷/余额方向”两个字段：方向为借计入借方、贷计入贷方，两者缺一不可。同一凭证后续分录的日期和凭证号留空时，导入器会在连续数据行内继承上一行凭证标识，并保留每行原始内容供核对。

多份余额表是不同时间点的快照，“科目余额”页一次只显示所选的一份，不会把几个月的期末余额相加。“明细账”中的期间筛选也作用于辅助核算和导出；余额表与明细是否覆盖同一期间仍需人工确认。

跨表核对只使用所选来源及期间。余额表本期借贷与明细逐科目比较；资产负债表项目与所选科目的期末余额比较；利润表项目与所选科目的期间发生额比较。报表项目可能汇总多个科目，必须由使用者确认对应关系；空白金额、缺失科目或失效来源标为“待核”，不当作零值或账务错误。重新导入后，如果关注凭证内容发生变化或原凭证无法匹配，标注会保留供复核，暂不写入 MD。

支持 `.xlsx`、`.xlsm`、`.xls` 和 UTF-8 CSV。序时账/明细账既支持借贷分列，也支持“金额单列＋借贷方向”格式（如用友导出的“日期/凭证号数/科目/摘要/方向/金额”，凭证号“记-0001”这类字号的合并形式原样保留）；余额表支持“余额金额＋余额方向”格式；两行表头可分别识别期初、本期发生、本年累计和期末的借贷列。方向列只认 借/贷（或 Dr/Cr），识别不了的方向按疑点阻塞该行，绝不猜测。核算维度明细行不计入科目合计，避免重复相加。资产负债表可识别双侧表头，利润表最多保留三列金额。无法可靠识别的版式仍需逐张校对。公式单元格需要原文件保存了计算结果；如果预览为空，请先在 Excel 中重新计算并保存副本。

## 当前能力与边界

| 模块 | 已实现 | 需要留意 |
|---|---|---|
| 导入 | `.xls/.xlsx/.xlsm/CSV`、多文件工作表自动分类、双层余额表表头、借贷分列或“金额/余额单列＋方向”两种画法、预览与手工映射、DeepSeek Flash 仅分析 1 行逻辑表头，复制任务给 Agent 建账、原行号及 SHA-256 留痕；重复来源可事务性替换 | 现金流量表自动略过且不提示；模型仍有限定预览范围；疑点需复核，复杂异构区域尚需单独处理；多文件期间重叠不自动去重 |
| 浏览 | 可展开科目树及父科目穿透、明细、凭证分录；虚线表格与温和的借贷区别；三处表格可分别设置显示列；报表项目穿透明细；页内搜索、期间筛选及表头排序；CSV 导出；余额表来源选择 | “凭证”按会计年度＋期间＋凭证字＋凭证号重组，缺少期间时按日期；并非原始凭证图片 |
| 核对 | 余额滚动、所选余额表与明细本期发生额、确认映射后的报表项目比较、凭证借贷、跨文件疑似重复 | 需人工确认期间、来源和报表项目对应科目；范围不全时标为“待核” |
| 关注凭证 | 账套内标注与多行注释、按科目索引的一键 MD 更新 | 凭证是根据已导入明细重组的，内容变化后需复核再导出 |
| 尽调主体名单 | 当前账套手动维护名称、身份（多选）、关系、别名和备注，支持带身份的批量导入；明细与 CSV 标示精确匹配结果；名称与身份按身份分组随 AI 审查发送云端 | 不从摘要或模糊包含关系推定关联方身份；备注与关系不发送 |
| Jev 尽调筛查 | 完整范围快照、逐页隐私确认、十三个尽调分类（可多分类、规则/Jev/用户三来源）、查看优先级（非风险等级）、程序特征（金额关注线、占比、分位、对手排名）、低价值机械凭证跳过与异常恢复、忽略反馈、规则版本及人工复核 | 云端功能须主动确认；中文效果与默认阈值尚待真实账套校准 |
| 数据 | 本地 SQLite，金额按分存储，原文件不改动 | 未提供文件加密和用户权限；请按案件保密要求保管账套与源文件 |

如果企业仅提供某一科目的明细，点开凭证时可能缺少其他科目分录；“核对提醒”会提示这种可能。没有凭证号的行无法可靠归并为一张凭证。科目名称和编码不一致、父级与明细级科目同时出现在余额表时，使用者需要确认科目级次和统计范围。

## 技术选型与模块

- `ledger_viewer/importer.py`：解析文件、字段映射、金额与日期标准化。
- `ledger_viewer/store.py`：本地数据模型和只读查询；导入操作作为单个事务，失败则回滚。
- `ledger_viewer/checks.py`：独立核对规则，只输出差异，不修改数据。
- `ledger_viewer/reconciliation.py`：按用户确认的来源、期间和项目映射比较报表与账簿。
- `ledger_viewer/voucher_notes.py`：保存关注凭证及注释，生成按科目索引的 MD。
- `ledger_viewer/related_parties.py`：按用户维护名单对往来单位和辅助核算作精确匹配；名单扁平化及批量导入解析。
- `ledger_viewer/import_preview.py`、`deepseek_mapping.py`：本地定位表头，只向 DeepSeek Flash 发送 1 行逻辑表头并校验列建议。
- `ledger_viewer/table_tools.py`：单元格选择、快捷键复制和本地加减侧栏。
- `ledger_viewer/jev_mapping.py`：共享字段定义和 Jev 密钥管理；导入界面不调用 Jev 列建议。
- `ledger_viewer/grid_lines.py`：为可滚动表格绘制浅色虚线分隔。
- `ledger_viewer/background.py`、`import_work.py`：可取消的本地后台任务与导入处理；界面更新留在主线程。
- `ledger_viewer/ui.py`：桌面窗口；不承担会计计算。
- `ledger_viewer/analysis_api.py`：只读分页分录接口及关键词候选接口；完整筛查不使用 5,000 行关键词候选上限。
- `ledger_viewer/jev_rules.py`、`jev_review.py`、`jev_ui.py`：版本化规则、确认快照与后台批次、结果与复核界面。
- `ledger_viewer/jev_runtime.py`：共用 Jev 请求并发限制。
- `ledger_viewer/jev_calibration.py`：离线统计人工标注样例的召回、误报、低分漏检与未完成数量。

下一阶段继续适配其他真实企业样表（可脱敏）：更复杂的多行表头、合并单元格、金蝶/用友不同列名、辅助核算单独表、借贷方向其他表示法和分月文件覆盖范围。Jev 已支持“借款与实缴出资”等核查主题；下一步由律师标注虚构样例、单独验证默认规则及阈值，并继续保持账面事实、模型判断和待补证据的区分。
