# AI 审查按提示词判断与验证

日期：2026-11-11。

## 当前行为

- 新的专项审查批次直接按照基础提示词及每项问题判断“命中／不命中”。百炼和 Jev 使用明确选项返回值，DeepSeek 使用有原文依据的命中列表。
- 专项设置取消“谨慎／中／宽松”、模型概率阈值、金额关注线、金额占比、科目分位和占比基数。新批次不再调用原有金额筛选计算，也不发送自动计算的比例或排名。
- 结果列表取消决策概率与查看优先级列，详情逐项展示命中或不命中及固定核查建议。信息不足仍按对应提示词单独判断；分段结果合并各片段的明确命中，不计算平均分或换算比例。
- 页眉“设置”中的入口改名为“AI审查设置”，偏好设置和 AI 页中的提示词入口同名。
- 继续保留科目范围、完整凭证上下文、已取得的历史候选、发送前预览确认、模型回退、取消、缓存、过期检查及人工处理结果。

## 规则与历史兼容

读取旧专项规则时追加一版按提示词判断的规则，保留已有基础提示词、问题、核查建议、模型及百炼正反条件；移除旧版数值阈值，不修改原有规则记录。

旧批次继续绑定旧规则，历史返回不重写，也不会自动请求模型。重新审查须建立新批次并确认发送。数据库中的旧数值字段仅用于历史兼容，新模式不生成概率分数。新旧规则和请求不同，原有概率缓存不会被复用为新模式结果。

## 验证

运行 `.venv/bin/python -m unittest discover -s tests`：384 项通过。

重点验证：

1. 返回选项即使附带零置信度，也按明确返回的选项处理，不另加概率门槛。
2. 新模式仅返回概率而没有明确判断时，记为响应无效；不在本地偷偷换算命中。
3. 旧金额筛选设置不参与新批次，禁止调用数值筛选计算仍能完成审查。
4. 多片段结果合并明确命中和信息不足，完整保留问题编号。
5. 旧规则升级保留自定义文字、原始历史记录及旧批次查看能力。
6. UI 不再提供档位、比例和阈值控件，菜单名称及结果列符合本次修改。

本次采用离线模拟返回和 macOS 图形回归，没有付费调用真实模型；新判断方式的真实凭证命中效果仍需后续实测。此前的概率模型联调记录属于旧模式，不代表新模式的效果。

## 接口依据

采用模型返回的 `choice` 选项作为判断，不读取概率或置信度进行筛选。接口支持见 [TypeSafe Choice 文档](https://docs.typesafe.ai/primitives/choice) 和 [阿里百炼决策模型接口文档](https://help.aliyun.com/en/model-studio/decision-model-api)。
