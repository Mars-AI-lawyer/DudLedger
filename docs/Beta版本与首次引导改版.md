# Beta 版本与首次使用引导

## 界面与操作

- 软件版本为 `0.3.0b1`，界面显示 `0.3.0 Beta`；打开账套后标题也保留 Beta 标识。
- 图标保留原有角色与账簿，增加 BETA 角标；应用运行图标和后续打包使用同一图片。
- AI 审查设置改为左侧科目与条目树、右侧编辑内容。新增科目可从当前账簿选择或自行输入，选择现有科目时自动带入编码；每个科目可以添加多个条目。
- 条目名称与审查提示词必填，核查建议可选。科目编码、百炼判断条件、通用提示词分别放入独立页面。
- 修改提示词时，未同步修改的旧百炼判断条件会清空，避免旧条件覆盖新意图；也可在高级页面重新填写条件。
- 保存产生新的规则版本，仅影响后续批次。历史批次继续使用原规则。删除科目或条目前会确认，未保存退出时提醒。
- 抽查范围自动读取当前账套已设置的科目，可多选；未选择时审查全部已配置科目。范围区域可滚动，避免科目增加后挤占结果区。
- 所有标准复选框统一显示勾号，保留原有键盘与变量行为。

## Excel 与保存目录

- 首次导入默认在原 Excel 所在目录自动创建同名 `.sqlite` 账套，不再额外弹出保存窗口；同名时依次增加 `-2`、`-3`。
- 一次导入多个文件时，以所选首个文件的目录为准。已有账套打开时，继续导入当前账套。
- “设置 → 偏好”可选择原表同目录，或选择固定文件夹。已存在的账套不会移动。
- 创建目录或文件失败时提示选择其他目录，取消后不继续导入。创建文件采用排他方式，避免覆盖已有文件。
- 复杂表格的 Agent 任务使用相同的目录偏好。

## 主界面聚光灯引导

原六步大窗口介绍已替换为主界面内的聚光灯提示，详见《聚光灯引导改版与验证》。引导依次介绍导入、科目、凭证、问题收集、AI 筛查和设置，每步约 300 像素宽的小卡片，只强调一个真实入口。

完成或跳过后保存状态，不再自动弹出；“帮助 → 重新查看使用引导”可重看。密钥表单保留在“设置 → AI 服务”，引导本身不读取、保存或发送密钥。

AI 审查提示仍说明日期、摘要、金额等会发送至模型企业，提醒用户酌情使用；实际发送内容以发送预览为准。凭证号继续用于本地关联，未新增上传字段。

## 图标来源

使用内置图片编辑工具，以原图为基础添加 BETA 角标。最终资源：`ledger_viewer/resources/icon-beta.png`，并更新根目录的 `图标.png`。

使用的提示词：保留角色、账簿、勾号、奶油色圆角背景、浅绿色形状和深色线条，在左上角留白处增加陶土色圆角徽章，白色文字严格为“BETA”，其余内容保持原样，输出单张正方形应用图标。

后续圆角修正：原图四角为不透明白色，导致运行图标呈完整方形。已保留原图案和 BETA 标识，使用透明 PNG 与规则圆角轮廓，圆角外侧完全透明。同步更新上述两份资源，验证了透明四角、主体不透明及运行时缩小后加载；未打包。

圆角处理提示词：保留全部内部图案，仅将奶油色圆角底板之外设为真正透明，清理白色杂点和光晕，保持平滑圆弧，不增加阴影。使用内置图片编辑工具提供透明底稿，并以本机图形渲染整理规则圆角边缘。
