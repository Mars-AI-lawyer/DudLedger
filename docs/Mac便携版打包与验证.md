# Mac 便携版打包与验证

本次版本为 0.3.0，制作于 2026 年 11 月 12 日。面向 Apple 芯片 Mac（arm64），已在本机 macOS 26.6 验证启动。尚未验证其他 macOS 版本；未提供 Intel 版。图标使用项目根目录的 `图标.png`。

## 使用

解压分发包，双击“DudLedger.app”即可运行，也可把它拖到“应用程序”或其他文件夹。运行环境已内置，无须安装 Python。应用尚未使用 Apple 开发者证书签名或公证；通过网络接收的副本可能被 macOS 拦截，确认来源后可在“系统设置 → 隐私与安全性”查看系统提供的打开选项。

账套默认保存在当前使用者的 `~/Documents/DudLedger/账套`，可自行调整。偏好设置位于当前使用者的 `~/.dudledger/preferences.json`，API Key 使用当前使用者的系统钥匙串；这些位置均不属于分发包。在原开发电脑运行时，仍可能读到该电脑此前保存的设置或钥匙串凭据，不能据此认为密钥被装进应用。

需要 Agent 接手时，点“复制提示词给我的 Agent”。便携版自动给出应用内可执行文件和 `--agent-import` 参数，源码版继续提供 Python 模块入口。Agent 直接按 `command_prefix` 参数列表执行，不把应用当 Python 解释器，不另装环境。应用移动后重新复制任务，保持入口和技能说明路径有效。Agent 需要能读取本机文件及运行本地程序。

## 打包边界

构建时先建立只含明确允许文件的中间目录：程序的 Python 模块、专项抽查通用规则 JSON、Agent 导入说明，以及指定图标。PyInstaller 仅分析这个入口和必要依赖。没有复制整个项目或用户目录，没有读取系统钥匙串，也没有将环境变量写入成品。

不打包个人配置、API Key、环境文件、Git 历史、工作区记录、项目文档、样例与测试资料、历史账套、Excel/CSV 业务文件、日志或本机凭据。运行时用户另行配置的 API Key 不会回写到应用包。

检查程序逐文件检查禁带文件、数据库文件头、外部符号链接和常见密钥特征，并解开标准库及内嵌 Python 模块检查内容。检查报告含文件清单、大小与 SHA-256。自动特征扫描不能识别所有形式的秘密；本次同时通过显式文件白名单限定材料来源。

## 复现构建

在 macOS、已安装本项目依赖的 Python 环境中执行：

```bash
python -m pip install 'pyinstaller>=6,<7'
python scripts/build_mac.py
```

产物为 `dist/DudLedger.app` 和对应架构的便携 ZIP 包；检查与签名验证通过后自动替换同名 ZIP。检查报告为 `build/mac/安全检查.json`。脚本自动将 PNG 生成 macOS 多尺寸 ICNS 图标，构建后执行内容检查；检查失败返回非零状态。构建工具版本：Python 3.13.12、PyInstaller 6.22.3。

## 首次使用与本次更新

第一次打开显示 AI 服务配置引导，先配置 DeepSeek 导入识别，再按需配置百炼和 Jev；支持稍后配置。引导有官方申请入口，并预填百炼决策接口地址。百炼须由使用者核实当前免费政策后勾选启用；未启用则跳过。凭证抽查固定按百炼、Jev、DeepSeek 顺序尝试，未配置或额度不足等情形顺延。程序不能查询账户计费状态，免费政策变化后应关闭百炼。

普通凭证与 AI 线索详情改为相对当前账套主窗口居中，直接进入备注时按展开尺寸定位，之后展开、收起备注保持当前位置。
