# 表头识别导入与 Agent 接手

更新日期：2026-11-11。文档沿用原文件名，便于已有链接继续访问。

## 默认流程：自动审查，确认一次导入

1. 选择一个或多个 Excel/CSV 文件。未打开账套时，沿用现有窗口选择新账套保存位置。
2. 默认勾选全部支持的工作表，读取完成后自动启动 AI 审查。现金流量表仍自动略过。
3. 默认向 DeepSeek Flash 发送原表前 20 行，最多 40 列、每格 60 字，并附上这一区域真实合并单元格的起止行列。原始行列位置与空格保持不变，AI 可结合标题、多层表头、横向及纵向合并信息和数据样本确定表头末行与列含义；三层、四层及更多层表头不再依赖本地两行猜测。前 20 行可能包含真实业务数据、公司名称和摘要；程序不另附文件名、真实工作表名或路径。预览不足时暂停并直接提供 Agent 接手入口，不自动扩大发送范围。
4. 使用统一流程校验表类型、表头行、列号与必填字段，再在本机运行整表预检和现有的本地疑点处理。当前窗口直接展示建议、拟导入行数、借贷合计、排除情况与提醒，此时尚未写入账目。
5. 全部勾选表通过后，主按钮“确认导入”启用。点击后再次核对原文件指纹，复用已审查的映射和预检结果写入账套，不重复请求 AI。原文件不修改。

任一勾选表失败、存在模型未解决的歧义或本地关键问题时，整批暂停。原因在当前窗口显示，“复制提示词给我的 Agent”突出显示；不要求先进入列调整窗口。可重试问题表、手动解决，或取消勾选问题表；其他已通过表的结果保留。模型的说明性提示和本地非阻断提醒可直接查看，不等同于识别失败，也不会仅因再点一次导入就绕过未解决的问题。

缺少密钥时，显示“设置 AI”和 Agent 入口，不自动弹出设置窗口；保存密钥后自动继续审查。密钥优先保存在系统安全凭据库，不可用时只保留在本次运行内存。已保存密钥时不逐次弹窗确认发送预览。偏好设置和导入窗口均明示前 20 行可能含真实账目。旧的 Jev／逐层识别偏好统一迁移为 DeepSeek Flash；导入不调用 Jev，不自动切换其他服务。

## 次要入口：手动设置

“手动设置…”菜单提供“调整当前工作表的列…”“仅用本地规则和手动设置”“恢复 AI 自动审查”。手动模式仍须通过同一套本地预检，全部勾选表通过后再确认导入；手动模式不会发送表头。手动保存的映射不被后续批量 AI 建议覆盖。

自动窗口与列调整窗口共用预览、映射校验和预检流程。默认都提供原表前 20 行及合并区域，不把列表中的初步表头行或表类型当成用户明确指定的值；只有用户主动按行号读取表头时，列调整窗口才仅发送该行在本地合并后的逻辑表头。AI 返回的表头结束行必须在发送范围内，不能切在映射列的合并区域中间。本地预览与模板匹配也支持逐层组合表头。后台任务取消后，迟到结果丢弃。

原文件发生变化时，同文件的旧审查结果失效，须重新审查并再次确认。预检前不进行部分导入；正式写入期间仍沿用单表事务，单表失败回滚、已完成的表保留，并显示完成情况。成功表取消勾选；失败项可重试，不会重复写入成功表。重复来源仍需确认替换或跳过。

## 自行交给 Agent

“复制提示词给我的 Agent”只为当前勾选且尚未完成的工作表复制任务说明，包含文件、工作表、建议保存目录、本机 Python 与技能的准确位置，不包含密钥。只有用户主动粘贴到自己的 Agent 才开始外部处理。

- 随软件提供的 [导入技能](../ledger_viewer/skills/dudledger-import/SKILL.md) 供能读取本机文件和执行命令的 Agent 使用。
- 本地入口为 `python -m ledger_viewer.agent_import`，提供 `inspect`、`schema`、`validate`、`create` 四个操作。
- Agent 提交列映射 JSON，列号从 1 开始；程序负责金额解析、整表校验与账套写入。单列金额必须与方向同时映射。
- 方案绑定文件 SHA-256；文件变化须重新分析。排除行须说明理由，限定数据区域须解释区域外内容。
- 新账套在临时目录完整构建，全部导入和完整性校验通过后以不覆盖方式生成最终 `.sqlite`。失败不交付半成品，不修改已有账套。
- 来源、原行号、原行内容、预检报告与完整方案保存在本地账套。`--open` 可直接打开生成的账套。
- `--accept-warnings` 仅允许在核对后保留提醒，不能绕过关键解析错误，也不代表认可财务事实。

本地入口自身不联网，但外部 Agent 的模型可能接收它读取的内容；其读取范围不受内置“前 20 行、40 列”约束，应自行控制授权和使用环境。

## 边界与验证

仅凭表头不一定能分辨所有会计含义，尤其是未知列名、多币种口径和同一工作表内多个不同结构区域。此时需人工核对；不会自动发送第 21 行以后的真实分录补充分析。超过第 40 列的必要字段可以手动映射。缺失公式缓存、原数值已丢失的编码前导零等，仍需取得重算副本或原系统导出。

回归测试使用合成 Excel／CSV 与模拟模型响应，覆盖自动审查与确认分离、多表整批暂停、前 20 行发送范围、三层及四层合并表头、旧偏好和模板、手动映射保留、文件变化、任务取消与迟到结果、Agent 范围及大字体和长错误信息布局。不以模拟测试推断真实模型识别准确率。

2026-11-11 验证结果：完整测试共 409 项通过，另已检查 macOS 实际窗口中的正常建议页、20 号字体及长错误信息布局。模型请求使用合成样本和模拟响应，未据此评价真实模型的识别准确率；Windows 界面未实测。
