# 客户说“凭证里都有”，律师怎么查？我做了个小工具

做非诉律师，尤其是做尽职调查，绕不开查账、查凭证。

拿到一大堆合同和业务材料，我们总要核对：资料给全了吗？账上还有哪些交易没有提供合同？某笔款项究竟是什么性质，是否需要进一步追问？

这时候，财务账簿和凭证，往往是很重要的核查线索。

有时候，向公司补要材料，还会收到一句让人有些无奈的回复：

> “凭证里面都有呀，你们自己去查账就好了，还问我要什么？”

道理似乎没错。可落到实际工作中，律师手里有什么工具可以查？

财务人员有自己的财务软件，审计人员也有相应的查账工具。到了非诉律师这里，很多时候，我们面对的就是公司发来的几份 Excel：序时账、明细账，以及各种格式的导出表。

Excel 当然能看，也有很多好用的功能。但要从一条明细追到对应凭证，再看清这笔业务涉及的其他科目，操作起来往往没有那么顺手。

所以，我做了一个自己在尽调中一直使用的小工具：**DudLedger，一款面向律师的尽调查账工具。**

## 01｜从一条明细，快速找到对应凭证

先说最基本、也是我自己用得最多的功能：**在明细账里找到一条记录，双击打开对应凭证，查看这张凭证涉及的各科目分录。**

平时在 Excel 里查账，往往需要先记下日期和凭证号，再去其他表格中搜索、筛选，找出同一张凭证的其他分录。

一来一回，查一笔还好，连续查几十笔、上百笔，就很容易把时间花在反复定位上。

DudLedger 借鉴了金蝶、用友等财务软件中常见的查账操作：把客户提供的 Excel 导入后，按科目查看明细，筛选日期、摘要和金额，再打开对应凭证。

比如，在“其他应收款”中看到一笔需要关注的往来，打开对应凭证，就可以进一步看：同张凭证还涉及哪些科目？摘要写了什么？借贷双方如何对应？接下来应该向公司补要什么材料？

我自己在尽调中，就是用它来快速定位记录、查看对应分录，再顺着线索查阅合同和其他资料。

这里也说明一下：**凭证展示以实际导入的数据为限。** 如果公司只提供了部分科目的明细，其他分录不会自动补齐；账簿数据本身也不包含原始单据和凭证附件，这些仍需要另行调取。

## 02｜真正费事的第一步，其实是导账

“把 Excel 导进去”听起来很简单，做起来却很容易卡住。

金蝶导出的表格、用友导出的表格、企业定制 ERP 导出的表格，可能长得完全不一样。

有的表头只有一行，有的有好几层；有的把借方、贷方分开，有的用一列金额再加一列方向；还有合并单元格、标题行、空白行，以及写在表格上方的科目名称。

如果每次都要手动指定“哪列是日期、哪列是凭证号、哪列是摘要、哪列是金额”，导账本身就要花不少时间。

因此，我给这个步骤加上了 **AI 辅助识别**。

目前，内置导入默认使用 DeepSeek，读取所选工作表的前 20 行，结合表头、合并单元格和样本内容，分析表格结构，识别各列的含义。

随后，由本地程序完成整表预检，展示识别结果、拟导入行数和相关提醒。核对后确认导入，就能形成可反复打开、查询的本地账套。

**AI 帮忙理解格式，导入结果仍留给使用者核对。** 日期、凭证号、借贷金额等关键字段是否对应正确，可以在导入前查看。

## 03｜遇到特别复杂的表格，还可以交给自己的 Agent

当然，也有一些表格，仅靠前 20 行确实看不明白。

例如，整张表的科目名称只在某个位置出现一次，或者多个科目分段排列，中间夹着小计、标题和说明。此时，需要结合更多内容判断。

工具里为这类情况提供了一个入口：**“复制提示词给我的 Agent”。**

点击后，会准备好文件位置、待处理工作表和导入要求。把这段任务说明粘贴给自己使用的、具备本机文件读取和执行能力的 AI Agent，就可以让它继续分析 Excel 的结构，并借助配套导入工具完成校验，生成本地 SQLite 账套。

对使用者来说，目标很直接：让原本难以整理的 Excel，也有机会变成方便查询的账簿。

## 04｜查到以后，把计算、关注和问题整理接起来

除了看账和查凭证，我还加了几个自己在工作中比较需要的功能。

### 计算器：边查边算，留下计算过程

查账时，经常要把几笔金额加起来，或者把不同记录放在一起核对。

工具支持框选合计，也可以将不同选区的金额加入计算器，做加减计算，保留本次计算过程和来源，方便回看。

### 关注凭证：先把值得追查的记录留下来

看到一笔重要交易，暂时还不能下结论，但觉得后面需要再看，就可以设为“关注凭证”，写上备注。

之后集中查看这些凭证，继续核查，也方便整理阶段性的工作记录。

### 问题归类：围绕尽调问题，把凭证放在一起

查账到最后，我们通常需要围绕具体问题继续核查。

比如“股东及关联方资金往来”“某笔大额付款的合同依据”“某项交易的审批材料是否齐备”。

在“问题工作台”里，可以建立问题，把相关凭证归集进去，并记录问题描述和核查笔记。同一张凭证，也可以关联到多个问题。

这样，查账过程中发现的零散线索，就能逐步整理成后续补充材料、访谈和撰写报告时可以使用的工作记录。

## 05｜AI 初筛：先找出值得进一步核查的线索

另外，我还加入了 AI 凭证初步抽查功能，目前仍在 Beta 阶段。

这部分可以使用阿里百炼决策模型、TypeSafe Jev 等模型，按配置和可用情况调用，也支持 DeepSeek Flash。

其中，决策模型主要针对预设问题返回“命中／不命中”等判断结果，适合用来做初步筛选。

使用时，可以选择需要抽查的科目，调整审查提示词，让模型结合日期、摘要、科目、金额、往来单位，以及已维护的关联方名单等信息，判断是否出现值得关注的线索。

比如，是否出现与股东、实际控制人或关联企业有关的资金往来线索，是否有需要进一步了解背景的交易记录。

筛选出线索后，再由律师打开凭证、核对材料，决定是否关注、是否归入问题清单。

整个过程可以接起来：

**导入账簿 → 查询凭证／AI 初筛 → 人工复核 → 标记关注 → 归入问题 → 补充材料、继续核查。**

AI 的判断可能有遗漏，也可能误判。最终如何理解一笔交易，仍要结合合同、银行流水、原始单据、公司说明等材料。
