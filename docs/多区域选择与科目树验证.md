# 多区域选择与科目树验证

日期：2026-11-12。

## 当前操作

1. 拖动框选第一个区域；按住 Ctrl（Mac 也支持 ⌘）单击其他格子或继续拖出矩形，追加不连续选区。各区域分别显示边框。
2. 合计和计数使用实际选中的格子，区域之间的空隙不参与计算，重叠格子只计算一次。“＋ 加入”“－ 减去”将所有当前选区作为一步写入计算历史，支持整步撤销及来源回查。
3. “关注所选”“加入问题…”使用选区涉及的凭证，同一凭证多条分录只处理一次。有行首勾选时，继续优先使用勾选范围；“清空勾选”后恢复使用框选范围。张数显示在按钮和选择栏。
4. 不按修饰键重新框选会替换全部区域，Esc 清空；排序、筛选、翻页和切换科目清除旧选区。跨页合并凭证继续使用勾选。
5. 左上“科目树”展开或收起导航，可搜索编码、名称及点击切换；搜索子科目保留上级路径。编码科目包含子科目，点击“全部科目”取消范围。
6. 切换科目保留明细搜索、筛选和排序，回到第一页并清除上一范围的凭证勾选。科目树默认收起，按账套记住显示状态，可拖动分隔条调宽，独立于余额表的搜索。
7. 已移除凭证拖曳手柄、跨窗口鼠标抓取、悬停展开和投放目标。保留行首勾选、单元格拖动框选、列宽调整和工具区调宽。跨问题归集使用“加入其他问题…”。

## 验证结果

完整测试 **418 项通过**，覆盖：

- Ctrl 单击、Ctrl 拖动追加选区，空隙排除、重叠去重、复制留空、合计与计算来源快照。
- 多区域批量关注及加入问题，凭证去重、勾选优先、取消选择不写入、跨问题关联保留。
- 科目树搜索及父子层级、与余额表搜索独立、外部科目范围同步、显示状态保存、切换后勾选清空。
- 820×520 窗口及 13／17／20 号字体下展开科目树，批量按钮可用；原有工具区布局、工作台独立窗口与备注保存保护。
- 拖曳手柄和事件捕获入口已撤除，普通鼠标框选及其他调宽操作仍通过检查。

原生工具已查看临时合成账套界面，但坐标点击／拖曳仍未稳定命中预期控件，因此未将旧拖曳的真实鼠标流程标记为通过。这不证明 Tk 无法实现拖曳；本轮按用户允许移除的要求，撤除未能稳定验收的拖曳入口，使用明确的批量按钮完成归集。新增选择与科目切换的交互验证使用 Tk 事件测试；Windows 尚未进行原生窗口验收。
