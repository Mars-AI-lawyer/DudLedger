## 本轮行为

- 目录占满侧栏，只显示问题名称和凭证数，名称列自动填满宽度，不保留横向滚动条。
- 单击和方向键只选择；双击或回车进入同一侧栏中的问题详情，不切换中间账表。
- 详情按“相关凭证／问题记录”标签全高展示，移除旧的上下分隔条及折叠笔记区。
- 目录中新建、归集或重复归集后只更新名称、数量与反馈，不自动打开详情。
- 返回目录恢复搜索、选择和滚动；从左侧重新打开默认进入目录，停靠与独立显示保留当前视图及标签。
- 拖曳中悬停“返回问题列表”约 450 毫秒可回到目录继续投放。由稳定顶层窗口接收鼠标事件，避免源表格隐藏后拖曳失效；操作结束后恢复原事件绑定并释放抓取。
- 原有金额、批量关注、关联事务、凭证快照和保存冲突保护继续使用，不修改账套结构。

## 人工复验入口

```bash
.venv/bin/python tests/manual_interaction_qa.py
```

该入口只创建临时合成账套，不读取真实账簿，不发送网络请求。关闭后删除临时数据。

1. 目录中单击问题，界面不切换；双击才显示相关凭证，回车也可打开。
2. 勾选明细账中的两张凭证，从行首手柄拖入问题行：数量增加 2，仍显示目录；重复拖入数量不增加。
3. 双击该问题，确认日期、凭证号、摘要和金额显示正常；双击凭证打开完整分录。
4. 切换到问题记录，写入笔记，返回目录；搜索、选中项、滚动位置应恢复。再打开问题时默认显示相关凭证。
5. 从问题凭证表拖动一张凭证，悬停“返回问题列表”，目录展开后继续拖到另一问题；原关联保留，目标新增关联。Esc 或无效位置松开应取消。
6. 在详情中切换独立窗口与停靠，当前问题和标签保留；收起后从左侧重新打开时显示目录。
7. 在 1160×690 和大字号下确认目录能展示明显多于两三条问题，详情标签分别使用剩余高度。
