# 律师尽调问题工作台

## 使用方式

打开账套后，点击顶部“问题工作台”。点“＋新建”输入问题名称，随后可以填写问题描述、核查笔记和处理状态。

从明细账、关注凭证列表或凭证窗口的行首 `⋮⋮` 手柄拖动凭证：放到问题名称或问题下的列表中建立关联，放到“仅预览凭证”区域只查看。右键菜单提供相同入口，凭证窗口另有“加入问题…”按钮。在问题间拖动凭证会增加关联；不会移除原问题中的材料。侧栏关闭时可拖到窗口右边缘稍作停留后展开，Esc 取消。

问题目录常驻上方，点击问题编辑笔记，点击凭证查看详情，双击打开完整凭证。“定位明细账”可以跳到目标所在分页；需要清除科目或筛选时先提示。目录按问题展开，每次读取 100 张，不读取所有凭证快照；重复加入列表后部的凭证时只定位该条材料。

拖动侧栏左边界调整宽度，拖动目录和详情间的分隔线调整比例。小窗口使用覆盖侧栏，详情和计算历史可以滚动；主窗口的科目总览、明细账分别保留计算记录，非表格页面沿用最近的计算来源。独立凭证窗口保持独立计算。

## 保存与材料独立性

- 停止输入约 800 毫秒后自动保存；切换、收起、替换凭证窗口和退出账套前完成保存。失败时保留输入并阻止丢弃，界面显示具体原因。
- 问题笔记属于问题；凭证关注备注在工作台、关注列表、普通凭证窗口和 AI 线索详情间同步。干净的编辑器同步最新内容，有未保存输入的编辑器保留自己的文字，比较原值后再写入，避免覆盖较新的备注。
- 备注冲突或问题版本冲突后，可点“重读已保存…”：先复制当前输入到剪贴板，再读取最新保存内容，便于合并。读取前会要求确认。
- 新增问题关联时同步关注，但取消关注不会删除问题材料；移除关联或删除问题也不会取消关注。取消关注仍按原规则删除全局关注备注，问题描述、问题笔记和凭证快照保留。
- 凭证快照不受备注修改和关注确认操作影响。来源内容变化时显示复核提示，可切换当前分录与归集时快照；仅在明确确认复核后更新问题共用快照。原凭证未匹配时仍可查阅快照及来源，但不能打开或定位不存在的原分录。

第一版不包含问题合并、手动排序、独立索证清单、AI 自动归类和按问题导出。

## 实现与兼容

- `ledger_viewer/issue_store.py`：问题、独立凭证引用及多对多关联的 SQLite 表、事务、问题版本检查和备注比较写入。
- `ledger_viewer/workbench.py`：右侧工作区、延时保存、备注同步、目录分页和专用拖动事件。
- 原有 UI 接入统一计算侧栏及备注服务，表头筛选坐标包含新增拖动手柄宽度。拖动手柄不属于数据列，不进入框选、复制或计算。

账套初始化时仅新增 `dd_issues`、`dd_voucher_refs`、`dd_issue_vouchers` 及索引；凭证关联不依赖导入分录的临时行 ID，也不以关注表为外键。现有账套格式标识不变，既有数据、关注和 MD 导出继续兼容。本功能没有新增依赖或云端请求。
