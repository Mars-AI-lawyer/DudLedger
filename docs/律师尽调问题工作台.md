# 律师尽调问题工作台

更新日期：2026-11-11。

## 界面与操作

左侧集中放置科目总览、明细账、财务报表、关注凭证、问题工作台、AI 尽调线索和计算器。默认使用图标窄栏，悬停显示名称，也可展开文字。顶栏保留页面标题、账套和导入入口。左下“账套”菜单提供导入记录、核对提醒及打开／退出账套。

财务报表页用分段按钮切换资产负债表和利润表；两表可以框选合计、复制、加入计算器，点击科目不再跳转明细账。不同报表分别保留来源、滚动位置和计算记录。

## 凭证选择

明细账、关注列表和问题凭证表使用相同的“勾选框＋拖曳手柄”。

1. 单元格拖动：框选、复制；明细账和报表还可合计。
2. 点击行首勾选框：选择整张凭证，同凭证分录的勾选同步；Shift 点击可连续勾选。
3. “本页全选”只影响当前显示行涉及的凭证；“清空勾选”清除跨页勾选。
4. 操作优先使用已勾选凭证；无勾选时使用框选涉及的凭证；再否则使用当前行。按钮、右键菜单及选择栏显示范围和张数。
5. 明细账翻页保留勾选；搜索、筛选、科目、排序或账套变化时清空。单元格框选不跨页。
6. 从已选凭证的手柄拖动整组，从未选凭证的手柄只拖动该张。单元格拖动不会归集凭证。

“关注所选”直接执行，不强制打开窗口。备注在凭证窗口或关注页单选后展开编辑。

## 归入问题

点击左侧“问题工作台”默认显示全高问题目录，只列问题名称和凭证数，保留搜索和新建入口。单击或方向键只选择问题，不加载凭证，不打开编辑器；双击问题或按回车，才在同一侧栏进入详情。目录不使用横向滚动条，长名称悬停可查看全文。

详情顶部固定显示“返回问题列表”、问题名称与凭证数；下方以“相关凭证／问题记录”两个标签切换，每个标签使用全部剩余高度，不再上下分割。相关凭证支持日期、凭证号、摘要、金额、复核状态及原有批量操作，双击打开完整凭证。问题记录集中编辑名称、状态、描述和核查笔记。每次打开问题默认进入相关凭证标签。

返回目录会恢复搜索词、选中项及滚动位置；保存失败时留在当前详情并保留输入，不能切换标签、返回、收起或切换宿主。

选择凭证后，点“加入问题…”或右键执行，可选择已有问题或新建并加入。在目录中拖到问题行，或在详情中拖到当前问题凭证表，都可加入；目录空白处松开可选择问题。归集和新建问题后保持目录，不自动打开凭证；详情中向当前问题归集时保留当前详情和标签。

从问题详情的凭证表拖往其他问题时，在“返回问题列表”按钮上停留约 450 毫秒，目录展开后继续投放。源表格隐藏时由稳定的顶层窗口继续接收拖曳事件；保存失败则不离开详情。右边缘停留可展开收起的工作台；Esc、无效投放或取消选择问题不写入数据。

同一凭证可以加入多个问题。跨问题拖曳增加关联。重复加入自动去重；批量关注、关联或新建问题并加入，任一步失败整批回滚。

| 操作 | 关注和备注 | 问题关联 |
|---|---|---|
| 加入问题 | 自动关注，已有备注不变 | 新增目标关联 |
| 移除关联 | 保留 | 仅移除所选问题中的关联 |
| 删除问题 | 保留 | 删除该问题及其关联 |
| 取消关注 | 删除关注及备注，集中确认 | 保留 |

## 展开与收起

问题侧栏默认约 440 像素，计算器默认约 320 像素；拖动工具区左边的浅色分隔条调整宽度，两种工具在本次窗口内分别记住宽度。展开工具区时，主表按可用空间临时适配各列宽度，不改变字体；收起后恢复原列宽和横向位置。“独立窗口”将工作台展开为可移动到第二屏的大窗口，继续沿用“目录 → 详情”展示方式，保留当前视图和详情标签。独立窗口“停靠右侧”返回侧栏；关闭只收起，从左侧入口可唤回。

主窗口空间不足以同时保留工作台和当前主表各列的最小宽度时，工作台自动独立显示，不覆盖账表。主表至少保留 525 像素，并随显示列数增加这一下限。显示列很多或窗口很窄时，计算器旁的主表仍允许横向滚动，以保留列的最小可读宽度。切换会先保存草稿，失败则保留输入并阻止切换。目录选中项与已打开的问题分别记录；停靠和独立显示切换会保留当前视图、标签、已加载凭证、勾选及滚动位置。从左侧重新打开工作台，默认返回目录。工作台独立显示时，主窗口仍可打开计算器。

## 金额与来源

关注列表显示日期、凭证号、摘要、金额、中文科目、备注和复核状态。工作台显示日期、凭证号、摘要、金额及复核状态。摘要合并去重，悬停可看全文；多日期显示范围。

金额只使用当前账套已导入分录的借贷金额：借贷相等时显示单边合计；不等时显示“借 ××／贷 ××”，提示“已导入借贷不一致”，不会把两边相加。负数保留符号；缺失凭证且无快照时不把未知金额显示成零。

归集时保存快照，重新导入后关联仍保留。原凭证未匹配时，双击打开只读快照；“更多 → 查看所选归集快照”可回查原内容。“确认已复核所选凭证”更新归集快照，关注记录的复核状态另行确认。编辑备注不确认凭证变化。

## 保存与性能

问题描述、核查笔记和关注备注停止输入约 800 毫秒后自动保存。切换、收起、关闭和退出账套前完成保存。并发修改使用版本检查，冲突保留各自输入，可先复制再重读数据库内容。

问题凭证默认加载 100 张，后续点击“加载更多”。目录只读取问题及数量，单击不查询凭证明细；打开详情后使用批量凭证读取，只处理已显示的凭证，不逐张调用预览。新加入或重复加入的远端条目可固定显示，避免为定位一张凭证加载全部历史列表。

数据保存在原账套内，不增加云端调用，不变更凭证标识和现有业务表结构。
