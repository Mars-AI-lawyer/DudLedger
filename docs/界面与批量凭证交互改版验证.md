## 可复现的人工验收

关闭其他验收窗口后，在项目根目录运行：

```bash
.venv/bin/python tests/manual_interaction_qa.py
```

此入口自动生成临时账套、514 条合成分录、两张报表、三个问题及三张关注凭证，不读取真实账套，不发送网络请求。关闭后临时文件删除。

1. 勾选第一、第二张凭证，同号的借贷分录应同步勾选；从手柄拖到“出资真实性”，问题计数应增加 2，表中金额分别显示 100.00、200.00。
2. 重复拖入同一问题，计数不增加；拖到另一个问题时原关联保留。
3. 从未勾选凭证手柄拖动，只加入该张。普通单元格拖动只框选，不归集。
4. 框选多张凭证的分录后右键“加入问题”，应按整张凭证去重。已有勾选时菜单张数使用勾选范围。
5. 勾选后翻页再返回，勾选应保留；更改排序或搜索后清空。
6. 从关注页勾选多张，拖入问题；取消关注应一次确认备注影响，并保留问题关联。
7. 工作台展开为独立窗口后，拖入另一问题。双击凭证打开分录窗口，单击不替换问题笔记。
8. 收起工作台，从手柄拖到主窗口右边缘停留，展开后投放；Esc 和无效投放应取消、不写入。
9. 财务报表框选银行存款 1000.00 与其他应收款 -125.15，合计应为 874.85；复制保留两行，点击项目不跳转。
10. 调整主窗口大小、字体及侧栏；问题笔记入口和主要按钮应可见，主表空间不足时工作台独立显示。编辑笔记后停靠、收起、重新打开，内容应保留。
