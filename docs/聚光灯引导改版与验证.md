# 聚光灯引导改版与验证

## 本次变化

原来的大窗口介绍和逐页密钥表单已移出首次引导。现在直接在主界面内，围绕六个真实入口展示小提示卡：

1. 导入表格：选择 Excel，识别前 20 行，核对后导入；复杂表格可复制任务给 Agent。
2. 科目总览：按科目汇总账簿，再查看明细。
3. 明细账：双击一行打开完整凭证，并可关注、填写备注。
4. 问题工作台：集中收集尽调问题、关联凭证和核查备注。
5. AI 尽调线索：选择科目和提示词，预览后发送；提醒 Beta 阶段与数据上传。
6. 设置：按需填写 DeepSeek、百炼密钥；保留预填试用地址和官方专属地址配置说明。

## 视觉与操作

- 遮罩仅覆盖主窗口内容区域，标题栏保留移动、缩放和关闭能力。
- 深色遮罩透明度约 58%；重点区域为真实透明镂空，原控件保持原有颜色、亮度，不使用截图替代。
- 高亮四周留 8 像素空隙，采用圆角和轻描边；每步只强调一个入口。
- 卡片嵌入主窗口，宽 300 像素，圆角、浅描边、轻阴影；在目标周围自动选择空位，限制在窗口以内。
- 每步使用简短标题和两句话；底部保留进度、下一步、低调的返回及跳过。最后一步为“开始使用”。
- 步骤切换使用约 72 毫秒、3 像素的小幅位置过渡；遮罩保持稳定。
- 引导期间阻止对其他区域的误点击，不允许直接操作高亮入口；点击遮罩不会退出。相关菜单与导入、打开账套等快捷键暂时禁用，退出时还原。
- 跟随主窗口的移动、缩放及 Tk 显示缩放变化；当前账套已打开时，相关步骤切换到对应页面。引导退出后恢复原页面与侧栏状态。
- 完成或跳过后保存 `onboarding_seen`，后续不自动出现；“帮助 → 重新查看使用引导”可随时重看。正在显示时重复打开不会创建多个引导。
- 直接关闭软件会清理浮层，不将未完成的引导记录为已完成。

## 设置与隐私

密钥继续在“设置 → AI 服务”填写。引导本身不读取密钥、不调用模型、不创建演示账套、不修改客户账簿。

AI 步骤保留数据说明：实际审查会向模型企业发送日期、摘要、金额等内容，提醒用户酌情使用；具体内容以发送前预览为准。

## 第一步按钮无法点击的修复

用户反馈第一步“下一步”和“跳过”无法点击。检查发现：原实现的圆角镂空只是视觉透明，原生遮罩窗口仍占据整个主窗口范围，可能截住提示卡按钮的鼠标事件。此前测试直接向遮罩注入事件，绕过了原生窗口的拦截，不能证明真实点击可达。

现将遮罩拆成提示卡上、下、左、右四个无边框窗口，窗口的实际范围均不与提示卡相交；目标控件的视觉圆角镂空继续保留。按钮由主窗口内的正常控件直接接收输入。提示卡圆角外侧背景同步匹配遮罩颜色，避免出现浅色方形边角。

新增后台回归先检查窗口范围是否挡住按钮，再执行按钮本身的按下、松开处理。旧实现的“第一步下一步”和“第一步跳过”检查均失败；修复后，引导输入与卡片位置共 7 项无界面检查通过，涵盖全部步骤、返回、完成、遮罩误点、窗口尺寸和位置变化，以及两种原生透明模式和降级模式。
