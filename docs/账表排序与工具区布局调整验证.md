# 账表排序与工具区布局调整验证

日期：2026-11-11。

## 本次调整

1. 明细账保留点击列名切换升序、降序，并在表头筛选窗口增加“升序（从小到大）”“降序（从大到小）”入口。排序沿用已有筛选，覆盖全部查询结果及 CSV 导出。新增原币金额、会计期间、年度、往来单位、核算维度、币别和制单人排序；原币金额按精确十进制比较，期间按数值比较。
2. 问题工作台、计算器使用可拖动的浅色分隔条，并在本次窗口内分别保留宽度。打开侧栏时临时压缩主表列宽，保留字体和各列；收起时恢复原列宽及横向位置。长内容支持悬停查看全文。工作台空间不足时独立显示；显示列很多或窗口很窄时，计算器旁的主表仍允许横向滚动，避免突破最小列宽。
3. 财务报表和凭证界面隐藏“来源行”。历史凭证显示偏好也过滤这一列，显示列设置中不再提供该列。来源数据继续保留，用于回查和计算过程快照。
4. 在偏好设置底部添加默认折叠的“账套辅助文件说明”，说明 `.sqlite-wal` 写入日志和 `.sqlite-shm` 共享内存索引的作用、自动管理方式及关闭账套后再复制或移动的操作。
5. AI 专项抽查科目使用专门的勾选图标，选中时显示绿色对勾，保留原有点击、键盘和抽查范围逻辑。

## 验证结果

运行 `.venv/bin/python -m unittest discover -s tests`：378 项通过。

新增回归覆盖：原币高精度金额排序与导出一致、筛选后两种排序方向、工作台和计算器展开后的主表列宽及高度、收起后恢复列宽、模拟拖动分别调整宽度、历史凭证设置与导入报表隐藏来源列、辅助文件说明折叠、对勾控件与抽查范围关联。
